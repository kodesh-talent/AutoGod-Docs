# $thread - 并发编程

- 更新时间:2026-10-22 10:55:51

> 多线程（并发）工具对象（脚本里的全局对象 $thread）。
> 
> 脚本默认是“一条路走到底”的：一行行往下执行，碰到耗时操作（比如等待、循环、截图识别）时会卡住。
> $thread 让你能再开几条“后台小路”同时干活：
> <ul>
>     <li>run / 运行：直接在后台启动一个任务（创建并立刻开始）；</li>
>     <li>create / 创建：先造好一个线程对象，需要时再手动 start 启动；</li>
>     <li>loop / 循环：创建一个“每隔一会儿自动跑一次”的循环器；</li>
>     <li>ui / 界面：切回界面主线程去操作界面控件；</li>
>     <li>has / get / stop / stopAll 等：管理这些线程的查询与停止。</li>
> </ul>
> 新手记住：后台任务里要“边做事边睡一会儿”，用全局 sleep(毫秒) 停顿，否则会一直占满 CPU。



```javascript
//在后台开一条线程跑一个耗时任务，不阻塞主线程
$thread.run(function() {
    log("后台任务开始");
    sleep(1000);                 //在后台睡 1 秒
    log("后台任务结束");
});
log("主线程不会被卡住，继续往下走");
```




### 界面(任务回调)

> 切到界面主线程执行（ui 的中文写法，作用完全一样）。
> 输出：void，表示没有返回数据；不要把调用结果当作成功标志。

- 参数 : 任务回调 {function} 要在界面主线程里执行的代码，写成 function() { ... }
- 版本 : 1.7.0


```javascript
//后台线程里干完活后，切回主线程操作界面
$线程.运行(function() {
    等待(1000);
    $线程.界面(function() {
        日志("现在运行在界面主线程里");
    });
});
```


### 运行(任务回调)

> 创建并立刻运行后台线程（run 的中文写法）。

- 参数 : 任务回调 {function} 要在后台执行的任务，写成 function() { ... }
- 返回 : {Threadx} 刚启动的后台线程对象
- 版本 : 1.7.0


```javascript
//启动后台任务，并拿到线程对象
var 线程对象 = $线程.运行(function() {
    for (var 次数 = 0; 次数 < 5; 次数++) {
        等待(500);
        日志("后台第 " + 次数 + " 次");
    }
});
//以后想停止它
线程对象.停止();
```


### 创建(任务回调)

> 创建线程（create 的中文写法）：只创建不启动，自动生成线程名称。
> 
> 创建后需要手动调用线程对象的 start() 才会开始运行。

- 参数 : 任务回调 {function} 这个线程要执行的任务，写成 function() { ... }
- 返回 : {Threadx} 创建好的线程对象，需调用 start() 才会运行
- 版本 : 1.7.0


```javascript
//第一步：创建线程（尚未运行）
var 线程对象 = $线程.创建(function() {
    for (var 次数 = 0; 次数 < 10; 次数++) {
        等待(300);
        日志(线程对象.名称() + "==>" + 次数);
    }
    日志(线程对象.名称() + "执行完毕");
});
//第二步：手动启动
线程对象.start();
```


### 创建(线程名称, 任务回调)

> 创建带名字的线程（create(名字, 任务) 的中文写法）：只创建不启动。
> 
> 给线程起个好记的名字，之后能用名字查找或停止；创建后需手动 start() 启动。同名时返回已登记的线程；同一个线程对象不能启动第二次。

- 参数 : 线程名称 {string} 给这个线程起的名字，之后靠它查找/停止
- 参数 : 任务回调 {function} 这个线程要执行的任务，写成 function() { ... }
- 返回 : {Threadx} 创建好的线程对象，需调用 start() 才会运行
- 版本 : 1.7.0


```javascript
//创建一个叫"下载任务"的线程
var 线程对象 = $线程.创建("下载任务", function() {
    for (var 次数 = 0; 次数 < 10; 次数++) {
        等待(300);
        日志(线程对象.名称() + "==>" + 次数);
    }
    日志(线程对象.名称() + "执行完毕");
});
//手动启动
线程对象.start();
```


### 新建倒计时锁(数量)

> 创建一个倒计时锁（newCdLock 的中文写法）：等多个后台任务都做完再继续。

- 参数 : 数量 {Number} 初始计数，传非负整数；内部取整数部分，负数会抛出异常，传 null 返回 null
- 返回 : {CdLock} 新建的倒计时锁对象；传入 null 时返回 null
- 版本 : 1.8.3


```javascript
//建一个计数器为 2 的倒计时锁
var 倒计时锁 = $线程.新建倒计时锁(2);
$线程.运行(function() {
    等待(500);
    倒计时锁.完成();           //任务完成，计数器减 1
});
$线程.运行(function() {
    等待(800);
    倒计时锁.完成();           //任务完成，计数器减 1
});
var 是否完成 = 倒计时锁.结束(5000);   //最多等 5 秒
日志("都完成了吗：" + 是否完成);
```


### 有(线程名称)

> 判断某个名字的线程是否存在（has 的中文写法）。

- 参数 : 线程名称 {string} 要检查的线程名字
- 返回 : {boolean} 存在返回 true，不存在返回 false
- 版本 : 1.7.0


```javascript
$线程.创建("下载任务", function() { 等待(1000); });
var 有 = $线程.有("下载任务");
if (有) {
    日志("这个线程存在");
} else {
    日志("这个线程不存在");
}
```


### 获取(线程名称)

> 按名字取出已存在的线程对象（get 的中文写法）。

- 参数 : 线程名称 {string} 要取出的线程名字
- 返回 : {Threadx} 对应的线程对象；没有这个名字时返回 null
- 版本 : 1.7.0


```javascript
$线程.创建("下载任务", function() { 等待(1000); });
var 线程对象 = $线程.获取("下载任务");
if (线程对象 != null) {
    线程对象.start();
}
```


### 循环(循环器名称, 执行回调)

> 创建一个循环执行器（loop 的中文写法）：让一段代码自动反复跑。
> 
> 返回的线程对象需调用 start() 才会开始循环；之后用 停止循环(名字) 停掉。

- 参数 : 循环器名称 {string} 给这个循环器起的名字
- 参数 : 执行回调 {function} 要反复执行的任务，写成 function() { ... }
- 返回 : {Threadx} 代表循环器的线程对象，需 start() 启动
- 版本 : 1.7.0


```javascript
//创建一个叫"循环1号"的循环器
var 线程对象 = $线程.循环("循环1号", function() {
    等待(1000);
    日志("我还活着！");
});
//启动它开始循环
if (线程对象 != null) { //重名或回调为空时拿不到线程，必须先检查
    线程对象.start(); //继承的线程启动方法，没有中文别名
}
```


### 有循环(循环器名称)

> 判断某个循环器是否存在（hasLoop 的中文写法）。

- 参数 : 循环器名称 {string} 要检查的循环器名字
- 返回 : {boolean} 存在返回 true，不存在返回 false
- 版本 : 1.7.0


```javascript
$线程.循环("循环1号", function() { 等待(1000); });
var 是否存在 = $线程.有循环("循环1号");
日志("这个循环器存在吗：" + 是否存在);
```


### 停止循环(循环器名称)

> 停止指定的循环执行器（stopLoop 的中文写法）。
> 输出：void，表示没有返回数据；不要把调用结果当作成功标志。

- 参数 : 循环器名称 {string} 要停止的循环器名字
- 版本 : 1.7.0


```javascript
var 线程对象 = $线程.循环("循环1号", function() { 等待(1000); });
线程对象.start();
//以后停止这个循环器
$线程.停止循环("循环1号");
```


### 停止(线程对象)

> 停止指定线程（stop(线程对象) 的中文写法）。
> 输出：void，表示没有返回数据；不要把调用结果当作成功标志。

- 参数 : 线程对象 {Threadx} 要停止的线程对象（用 run/create 得到）
- 版本 : 1.7.0


```javascript
var 线程对象 = $线程.运行(function() {
    while (true) {
        等待(500);
        日志("还在跑...");
    }
});
等待(2000);
$线程.停止(线程对象);        //停止这个线程
```


### 停止(线程名称)

> 按名字停止指定线程（stop(名字) 的中文写法）。
> 输出：void，表示没有返回数据；不要把调用结果当作成功标志。

- 参数 : 线程名称 {string} 要停止的线程名字
- 版本 : 1.7.0


```javascript
var 线程对象 = $线程.创建("示例", function() {
    while (true) { 等待(500); }
});
线程对象.start();
//按名字停掉它
$线程.停止("示例");
```


### 停止所有()

> 停止所有普通线程（stopAll 的中文写法，不影响循环器）。
> 输出：void，表示没有返回数据；不要把调用结果当作成功标志。
> 输入：无参数。

- 版本 : 1.7.0


```javascript
$线程.运行(function() { while (true) { 等待(500); } });
//脚本结束前一键停掉所有普通后台线程
$线程.停止所有();
```


### 停止所有循环()

> 停止所有循环执行器（stopAllLoop 的中文写法）。
> 输出：void，表示没有返回数据；不要把调用结果当作成功标志。
> 输入：无参数。

- 版本 : 1.7.0


```javascript
var 线程对象 = $线程.循环("循环1号", function() { 等待(1000); });
线程对象.start();
//脚本结束前一键停掉所有循环器
$线程.停止所有循环();
```
