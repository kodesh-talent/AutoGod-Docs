# $bus - 消息总线

- 更新时间:2026-10-22 10:55:45

> 消息总线（也叫事件总线）对象，脚本里叫 $bus。
> 
> 它像一个"广播站"：一个地方用 post 发布一条带名字的消息，另一个地方用 event 提前监听同名消息，
> 就能在收到消息时自动执行回调。常用于同一段脚本内部各部分之间互相传递消息、解耦代码。
> 



```javascript
$bus.event("taskDone", function(data) { log(data); });
$bus.post("taskDone", { ok: true });
```




### 罗列()

> 列出所有监听器

- 返回 : {字符串数组} 当前所有已注册监听器的名字列表；一个都没有时返回空列表
- 版本 : 1.8.9


```javascript
//获得所有监听器列表
var 监听器列表 = $消息.罗列();
log(监听器列表); //[我的监听器1号]
```


### 发送(监听器名称, 数据)

> 发送一条信息

- 参数 : 监听器名称 {字符串} 要发布的消息名字，必须和监听时用的名字一模一样才能收到
- 参数 : 数据 {对象} 要随消息一起带给监听者的数据，可以是任意类型
- 版本 : 1.6.8


```javascript
$消息.发送("我的监听器1号","我是数据");
```


### 监听(监听器名称, 监听回调)

> 添加监听
> 
> 这是上面 event 方法的中文写法，作用完全一样：登记一个名字和回调，以后收到同名消息就自动执行回调。

- 参数 : 监听器名称 {字符串} 要监听的消息名字，发布时名字一致才会触发
- 参数 : 监听回调 {function} 收到消息时要执行的回调函数，参数 数据 就是发布时带过来的数据
- 版本 : 1.6.8


```javascript
$消息.监听("我的监听器1号", function(数据) {
    log("获得数据:" + 数据);
    toast(数据);
});
```


### 关闭(监听器名称)

> 移除监听器

- 参数 : 监听器名称 {字符串} 要关闭的监听器名字（监听时登记的那个名字）
- 版本 : 1.6.8


```javascript
//指定关闭监听器
$消息.关闭("我的监听器1号");
```


### 清空()

> 移除所有监听器

- 版本 : 1.6.8
<p>教学示例：
<pre>{@code
$bus.清空();
log("已移除全部事件监听器");
}</pre>


```javascript
$消息.清空();//关闭所有监听器
```


### 停止所有()

> 关闭所有监听器

- 版本 : 1.6.8


```javascript
$消息.停止所有();//关闭所有监听器效果和'清空()'一样
```
