# $log - 日志

- 更新时间:2026-10-22 10:55:48



### toast(msg)

> 弹一个短暂的小提示（Toast），几秒后自动消失。

- 参数 : msg {String} 要显示的提示文字
- 版本 : 1.9.6


```javascript
$log.toast("操作完成");
```


### alert(msg)

> 弹出一个对话框，显示一段文字（标题固定为“提示”）。

- 参数 : msg {String} 对话框内容
- 版本 : 1.9.6


```javascript
$log.alert("这是对话框内容");
```


### alert(title, msg)

> 弹出一个对话框，可以自己指定标题和内容。

- 参数 : title {String} 对话框标题
- 参数 : msg {String} 对话框内容
- 版本 : 1.9.6


```javascript
$log.alert("标题", "这是对话框内容");
```


### i(msg)

> 打印一条“信息级”日志（用于记录普通提示信息）。
> 
> 可以一次传多段内容，会拼在一起显示。

- 参数 : msg {Object...} 要打印的内容，可传多个
- 版本 : 1.9.6


```javascript
$log.i("脚本开始", "版本1.0");
```


### d(msg)

> 打印一条“调试级”日志（开发调试时用）。

- 参数 : msg {Object...} 要打印的内容，可传多个
- 版本 : 1.9.6


```javascript
$log.d("调试变量的值是：" + 123);
```


### e(msg)

> 打印一条“错误级”日志（记录出错信息，一般醒目显示）。

- 参数 : msg {Object...} 要打印的错误内容，可传多个
- 版本 : 1.9.6


```javascript
$log.e("出错了：找不到文件");
```


### w(msg)

> 打印一条“警告级”日志（记录需要注意但不算错误的情况）。

- 参数 : msg {Object...} 要打印的警告内容，可传多个
- 版本 : 1.9.6


```javascript
$log.w("注意：网络较慢");
```


### show()

> 在屏幕上显示悬浮的日志小窗，方便边运行边看日志。

- 版本 : 1.9.6


```javascript
$log.show();
```


### close()

> 关闭屏幕上的悬浮日志小窗。

- 版本 : 1.9.6


```javascript
$log.close();
```


### ui()

> 打开完整的日志查看界面。

- 版本 : 1.9.6


```javascript
$log.ui();
```
