# $file - 文件系统

- 更新时间:2026-10-22 10:55:48

> 文件系统对象（脚本里写作 $file，中文名叫 $文件）。
> 
> 它是你操作手机里各种文件、文件夹的"工具箱"：可以读文件、写文件、创建、删除、复制、移动、
> 罗列目录里有哪些文件，还能查询手机里的图片、视频、音频媒体信息。
> 
> 新手提示：路径既可以写完整绝对路径（如 "/sdcard/Download/a.txt"），也可以写相对脚本目录的
> 相对路径（如 "./main.js"、"res"）。写入操作通常需要把文件放到外部存储（SD 卡）目录。



```javascript
// 读取一个文本文件的全部内容
var text = $file.read("/sdcard/Download/config.txt");
// 把内容写到另一个新文件里，完成一次复制
$file.write(text, "/sdcard/Download/config-copy.txt");
```




### 获得uri(路径)

> 获得 uri：把本地文件路径包装成可分享的 Uri。
> 
> 这是 $file.uri 的中文叫法，作用完全相同。当你习惯用中文写脚本时，可以调用它。

- 参数 : 路径 {字符串} 要转换的本地文件路径
- 返回 : {Uri} 包装后的 Uri 对象；转换失败时可能返回 null
- 版本 : 1.6.8


```javascript
// 把本地图片路径包装成 Uri，便于分享给其它 App
var uri = $file.获得uri("/storage/emulated/0/Pictures/小红.png");
log(uri); // 输出类似 content:// 开头的地址
```


### 打开(路径)

> 打开文件：根据路径得到一个 File 文件对象，不读取内容。
> 
> 这是 $file.open 的中文叫法，作用完全相同。

- 参数 : 路径 {字符串} 文件或文件夹路径
- 返回 : {File} 对应的 File 文件对象
- 版本 : 1.6.8


```javascript
// 得到脚本目录下 res 文件夹的 File 对象
var file = $file.打开("res");
log(file.getAbsolutePath()); // 输出完整绝对路径
```


### 是文件(路径)

> 是否是文件：判断路径指向的是不是一个文件。
> 
> 这是 $file.isFile 的中文叫法，作用完全相同；路径不存在时返回 false。

- 参数 : 路径 {字符串} 要判断的路径
- 返回 : {布尔值} 是文件返回 true，否则返回 false
- 版本 : 1.6.8


```javascript
// 判断 res 是不是文件（是文件夹，返回 false）
log($file.是文件("res"));
// 判断 main.js 是不是文件（是文件，返回 true）
log($file.是文件("main.js"));
```


### 是目录(路径)

> 是否是文件夹：判断路径指向的是不是一个目录。
> 
> 这是 $file.isDir 的中文叫法，作用完全相同；路径不存在时返回 false。

- 参数 : 路径 {字符串} 要判断的路径
- 返回 : {布尔值} 是文件夹返回 true，否则返回 false
- 版本 : 1.6.8


```javascript

// main.js 是文件，返回 false
log($file.是目录("main.js"));
```

> 
> 如果是文件，则判断文件内容是否为空；如果是文件夹，则判断文件夹是否为空。
> 这是 $file.isEmpty 的中文叫法。

- 返回 : {布尔值} 为空返回 true，有内容返回 false

### 拼接(父级, 子级)

> 路径拼接：把两段路径拼成一段，自动补好斜杠。
> 
> 这是 $file.join 的中文叫法，作用完全相同。

- 参数 : 父级 {字符串} 前面那一段路径
- 参数 : 子级 {字符串} 后面要接上去的那一段路径
- 返回 : {字符串} 拼接好的完整路径
- 版本 : 1.0.0


```javascript

log(路径); // 输出：sdcard/Pictures
```

### 罗列视频()

> 查询系统媒体库中当前可见的视频信息。
> 
> 输入参数：无。返回类型为 List&lt;VideoInfo&gt;，即 Java 列表，每一项是一个 VideoInfo 信息对象。
> 用 size() 取得数量，用 get(序号) 取出一项；第一项序号是零。不能把它当作脚本数组用长度属性和方括号读取。
> 查询按加入媒体库的时间从新到旧排列，只读取系统已经收录且当前应用可见的资料，不会遍历手机里的每个目录。
> 对象记录名称、路径、字节大小和以秒为单位的加入时间；修改这些对象不会修改真实文件。
> 播放时长单位是毫秒，除以一千得到秒数。
> 安卓十三及以上入口检查读取视频权限；没有通过检查时打印提示并返回空列表。
> 安卓十二及以下入口检查读取外部存储权限。媒体库没有可见记录或没有提供查询结果时也会返回空列表。
> 系统查询异常会向外抛出；下面用异常处理展示如何记录失败，空列表不一定表示手机没有这种文件。
> 下例使用中文脚本入口；返回的 Java 列表方法和信息对象的公开读取方法只有英文名称，按真实名称调用即可。

- 返回 : {List<VideoInfo>} 视频信息列表；数量为零时不要取第一项
- 版本 : 1.6.8


```javascript
try {
    // 先在设备上授予相应读取权限，再查询列表。
    var 列表 = $文件.罗列视频();
    if (列表 == null || 列表.size() === 0) {
        日志("没有可读取的视频记录，请检查权限和媒体库内容。");
    } else {
        // 逐项读取信息：序号从零开始，不超过列表数量。
        for (var 序号 = 0; 序号 < 列表.size(); 序号++) {
            var 信息 = 列表.get(序号); // 得到一个 VideoInfo 对象。
            日志("名称：" + 信息.getName());
            日志("路径：" + 信息.getPath());
            日志("大小（字节）：" + 信息.getSize());
            日志("时长（秒）：" + Number(信息.getDur()) / 1000);
            // 媒体库保存秒数；脚本日期对象需要毫秒。
            日志(new Date(Number(信息.getTime()) * 1000).toString());
        }
    }
} catch (错误) {
    日志("查询视频信息失败：" + 错误);
}
```
