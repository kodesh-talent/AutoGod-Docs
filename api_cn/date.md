### 解析(时间字符串, 模板字符串)

> 把日期时间文字解析为宿主 Date 日期对象。
> 输入：String 日期文字和 String 模板。模板要与输入格式一致。
> 输出：java.util.Date 对象；通常的解析失败返回 null。日期文字不能为空，模板无效等参数错误仍可能抛出异常。
> 按设备默认时区解析。解析器允许一定的日期自动调整，也可能只解析输入开头，因此不要把返回非空当作严格的日期合法性校验。

- 参数 : 时间字符串 {String} 要解析的非空日期文字
- 参数 : 模板字符串 {String} 匹配输入的日期模板，MM 表示月份，mm 表示分钟
- 返回 : {Date} 宿主日期对象；字符串解析失败时为 null
- 版本 : 1.6.8


```javascript
var 结果 = $日期.解析("2026-01-02 03:04:05", "yyyy-MM-dd HH:mm:ss"); //文字转成日期对象
if (结果 != null) {
    日志("解析后：" + $日期.格式化(结果, "yyyy年MM月dd日 HH:mm:ss")); //换一个模板展示
} else {
    日志("无法解析，请核对日期内容和模板");
}
```

### 信息()

> 把一个时刻拆成年、月、日、星期和时间等信息。
> 输入：无参数，使用调用时的当前时间。
> 输出：DateInfo，日期信息快照，可直接读取字段，也可以调用对应的读取方法。
> 日期的拆分和显示使用设备默认时区；改变设备时区可能改变同一时间戳显示出的小时和日期。
> 月份是一到十二；星期编号一代表星期日。快照不会自动随时间更新，中英文字段也不要手动修改后期望互相同步。

- 返回 : {DateInfo} 日期信息快照；字符串解析失败时为 null
- 版本 : 1.6.8


```javascript
var 结果 = $日期.信息(); //调用当前重载
if (结果 != null) { //字符串解析失败时不能继续读取属性
    日志("日期：" + 结果.年 + "-" + 结果.月 + "-" + 结果.日);
    日志("时间：" + 结果.时 + ":" + 结果.分 + ":" + 结果.秒);
    日志("星期编号：" + 结果.星期); //一表示星期日，七表示星期六
    日志("时间戳：" + 结果.获取时间戳()); //演示返回对象的读取方法
} else {
    日志("未取得日期结果，请检查输入");
}
```

### 时间字符串(毫秒)

> 把一段持续时间换算成天、时、分、秒的中文文字。
> 输入：Number 数值，单位为毫秒；这是持续时长，不是日期时间戳。内部先取整数毫秒，再舍去不足一秒的部分。
> 输出：String 字符串；零或负值得到 "0秒"，正数不足一秒也得到 "0秒"，传 null 得到文字 "null"。
> 结果省略数值为零的单位，一天按二十四小时计算，不受时区影响。

- 参数 : 毫秒 {Number} 要换算的毫秒时长；小数部分会被舍去
- 返回 : {String} 得到的日期或时长文字；具体空值行为见说明
- 版本 : 1.6.8


```javascript
var 结果 = $日期.时间字符串(90061000); //一天一小时一分钟一秒
日志("时长：" + 结果); //得到“1天1时1分1秒”
日志("不足一秒：" + $日期.时间字符串(500)); //得到“0秒”
日志("没有时长：" + $日期.时间字符串(0)); //得到“0秒”
```
