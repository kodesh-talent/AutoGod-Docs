# $permit - 权限工具

- 更新时间:2026-10-22 10:55:50

> 权限工具对象（脚本里写作 $permit），用来“申请”和“检查”安卓系统的各种权限。
> 
> 安卓为了保护隐私，很多功能（悬浮窗、无障碍、存储、相机、定位、短信、联系人等）都要先向用户申请、
> 用户同意后才能用。这个对象把每一种权限都封装成了一对方法：
> <ul>
>     <li>hasXxx()：检查“现在有没有这个权限”（只判断，不弹窗）；</li>
>     <li>xxx()：去“申请这个权限”（会跳到系统设置页或弹出授权框）。</li>
> </ul>
> 用户必须在系统界面完成授权；请求权限不代表系统一定会授予。
> 注意：在 $权限 中调用任何权限申请方法，一般只调用一次（已经有就不会重复弹）。



```javascript
//先检查有没有悬浮窗权限
var canFloat = $permit.hasFloaty();
if (!canFloat) {
    $permit.floaty(); //没有就去申请
}
```

### 有权限(权限名称)

> 判断是否有权限（中文方法名版本，作用和 hasPermit 完全一样）。
> 
> 注意：在$权限中调用任何权限,都只会调用一次

- 参数 : 权限名称 {字符串} 要查询的安卓权限全名，例如 "android.permission.CAMERA"
- 返回 : {布尔值} 已授予该权限返回 true，否则返回 false
- 版本 : 1.7.0


```javascript
//判断是否有获取账号列表权限
var ok = $权限.有权限("android.Manifest.permission.GET_ACCOUNTS");
//等同于
var ok2 = $权限.有权限("android.permission.GET_ACCOUNTS");
log("是否有该权限：" + ok);
```


### 有权限(权限名称数组)

> 判断是否有权限（中文方法名版本，作用和 hasPermit(数组) 完全一样）。
> 
> 注意：在$权限中调用任何权限,都只会调用一次

- 参数 : 权限名称数组 {字符串数组[]} 要检查的权限名数组
- 返回 : {布尔值} 数组里每一个权限都已授予才返回 true，否则返回 false
- 版本 : 1.7.0


```javascript
//要同时检查的一组权限

//判断这一组是否全部都有权限
var allOk = $权限.有权限(权限组);
log("是否齐全：" + allOk);
```
