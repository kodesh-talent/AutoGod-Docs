# YoloResultCell - 检测结果单元

- 更新时间:2026-10-22 10:56:19

> 单个目标检测结果，保存一个物体的类别、分数和位置。
> 
> 整体结果 YoloResult 的 getData() 返回 Java 列表，可先检查 size() 再用 get(下标) 取出本对象。
> 也可直接构造一个教学对象练习读写；手动填写数据不会启动检测，不代表图片中真的存在该物体。
> 公开字段可直接读写，但直接修改英文或中文字段不会同步另一个字段；setSimilar、setIndex、setLabel 才会同时更新两份。
> 坐标和宽高也是独立值。当前结果装配代码把 cx 算成 (x + w) / 2、cy 算成 (y + h) / 2，不能直接当作几何中心使用。
> 若需要根据左上角与宽高计算几何中心，应使用 x + w / 2、y + h / 2；裁剪图片的坐标还需换算到屏幕坐标。



```javascript
var cell = new YoloResultCell(); // 创建一个教学用目标。
cell.setLabel("phone"); // 同时填写两份类别名称。
cell.setX(100); cell.setY(200); // 设置左上角。
cell.setW(80); cell.setH(120); // 设置宽高。
var centerX = cell.getX() + cell.getW() / 2; // 计算几何中心横坐标。
var centerY = cell.getY() + cell.getH() / 2; // 计算几何中心纵坐标。
log(centerX + "," + centerY); // 输出一百四十、二百六十。
```




### const {float} 相似度;

> 保存识别分数。
> 
> 字段类型为 float。默认值为 -1，表示尚未填写。分数用于比较模型的检测结果，不保证识别一定正确。
> 这是公开字段，脚本可以直接读取和赋值。
> 英文与中文字段是两份独立存储；直接给其中一份赋值，不会自动改变另一份。统一填写时可调用 setSimilar，该方法会同步两份。


```javascript
var 目标 = new YoloResultCell(); // 创建练习对象，不执行检测。
目标.相似度 = 0.92; // 直接填写这一项字段。
日志(目标.相似度); // 读取刚填写的值。
```

> 设置方法会同时填写英文与中文字段；读取方法读取英文 label 字段。直接改中文字段不会影响这个读取方法。

- 参数 : label {String} 要保存的类别名称
- 返回 : {void} 无返回值


```javascript
var cell = new YoloResultCell(); // 使用教学数据练习这个方法。
cell.setLabel("phone"); // 写入指定类型的数据。
log(cell.getLabel()); // 读取保存值。
```


### json()

> 生成英文键名的结果文本。
> 
> 没有输入参数；返回 String（字符串），不是脚本对象。包含 similar、index、label 和各项坐标宽高。
> 两种输出都读取英文存储字段；单独修改中文字段不会改变这里的结果。
> 当前实现直接拼接文本，不转义标签中的引号、反斜杠或换行，特殊内容可能使文本不符合 JSON 格式。
> 若要保存任意文字，应自行整理脚本对象后用 JSON.stringify 序列化；不要默认这段文本一定可以 JSON.parse。

- 返回 : {String} 拼接得到的结果文本


```javascript
var cell = new YoloResultCell(); // 创建结果样本。
cell.label = "phone"; // 这里直接填写序列化实际读取的字段。
log(cell.json()); // 调用实际存在的方法，查看文本。
```


### json_zn()

> 生成部分中文键名的结果文本。
> 
> 没有输入参数；返回 String（字符串），不是脚本对象。相似度、下标、标签使用中文键名，x、y、cx、cy、w、h 仍是原键名。
> 两种输出都读取英文存储字段；单独修改中文字段不会改变这里的结果。
> 当前实现直接拼接文本，不转义标签中的引号、反斜杠或换行，特殊内容可能使文本不符合 JSON 格式。
> 若要保存任意文字，应自行整理脚本对象后用 JSON.stringify 序列化；不要默认这段文本一定可以 JSON.parse。
> 本接口实际方法名是 json_zn，没有另一个中文方法别名；中文脚本也应保留这个名称。

- 返回 : {String} 拼接得到的结果文本


