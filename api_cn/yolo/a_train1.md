# 训练模型-环境搭建

- 更新时间:2026-10-22 10:55:52

> 训练模型-环境搭建
> 
> 这个教程是适合小白的教程，但是你需要具备如下基础：会下载文件、会安装软件、会打字、会点按钮、会执行命令。




第一步：安装 Python 环境。

训练模型需要先在电脑上装好 Python（建议 3.10 这个稳定版本，和 ultralytics 兼容性最好）。

注意：不要下载最新版本，我规定下载这个版本当然是有说法的，不然后面安装依赖的时候报错别怪我。打开连接之后网页滑动到最后，找到适合自己电脑的版本下载安装即可，随便你安装到哪都行，但是你要知道自己安装的路径在哪，后面会用到。
安装时记得勾选 "Add Python to PATH"（把 Python 加入环境变量），否则后面命令行找不到 python。

装完后，可以在命令窗口输入 python --version，能打印出版本号就说明装好了。

这一步只是把运行环境准备好，还没开始装训练用的库。


## 打开命令窗口执行一堆命令

接下来要在"命令行"里敲命令装依赖。Windows 下可以在项目文件夹地址栏输入 cmd 回车，就能在当前目录打开命令窗口。

也可以按 Win+R 输入 cmd 打开，但那样默认在用户目录，需要自己 cd 到项目文件夹。

打开后先确认 python 和 pip 能用，输入 python --version、pip --version，有版本号输出即可。


第三步：用 pip 安装训练所需的库。

先升级一下 pip 自己，避免因为 pip 太旧而安装失败：

```
python -m pip install --upgrade pip
```

然后安装 ultralytics（这是 YOLOv8/v11 官方的训练库，会顺带把 torch 等依赖一起装好）：

```
pip install ultralytics
```

如果下载很慢，可以换成国内镜像源再装：

```
pip install ultralytics -i https://pypi.tuna.tsinghua.edu.cn/simple
```

装的过程中会下载很多依赖，耐心等它跑完，最后看到 Successfully installed 就算成功。

期间如果报错，多半是 Python 版本不对或没勾 PATH，回到第一步检查。
```


第四步：验证环境是否搭好。

在命令窗口输入 python 进入交互模式，然后 import ultralytics 试试。

如果没有任何报错，说明环境已经可以开始训练了。

接下来就可以准备自己的图片数据集、标注，然后进入下一篇训练教程。

环境只需要搭这一次，以后训练直接用即可，不用重复装。
