# $fc - 文件选择器

- 更新时间:2026-10-22 10:55:48

> 文件选择器对象，脚本里叫 $fc。
> 
> 它会弹出一个系统风格的文件浏览窗口，让用户手动挑选一个或多个文件（或目录），
> 选好后把选中的路径列表通过回调交给你。适合让用户自己选要处理哪个文件。
> 需要先授予悬浮窗和存储访问权限；缺少存储权限时申请后需要重新打开。



```javascript
$fc.show(function(files) {
    // 回调接收 Java 列表，不能用脚本数组的方式读取。
    for (var i = 0; i < files.size(); i++) {
        log(files.get(i)); // 逐项取得用户选中的路径。
    }
});
```




### 显示(回调)

> 打开文件选择窗口，等用户确认后把选择结果交给回调。
> 
> 输入回调类型为 FcResultCallback；脚本可以传入一个普通函数。函数接收 List&lt;String&gt;，即装有文件或目录路径字符串的 Java 列表。
> 返回类型为 void，没有同步返回的路径。用户点击确定时才调用回调；取消不会调用这个结果回调。
> 回调在界面操作中触发，应避免在里面执行长时间阻塞任务。
> 需要悬浮窗权限；缺少时提示后直接返回。底层发现缺少存储权限时会发起权限申请并返回，授权后需要重新调用显示方法。
> 此重载使用默认设置：单选文件，以外部存储根目录作为起点和根路径，不设置额外后缀筛选。

- 参数 : 回调 {FcResultCallback} 用户确定选择时调用的函数，参数为路径字符串列表，函数无需返回值
- 版本 : 1.5.8


```javascript
// 请先在设备上完成悬浮窗和存储权限授权。
$文件选择器.显示(function (路径列表) {
    // Java 列表用 size() 获取数量，用 get() 读取路径。
    if (路径列表 == null || 路径列表.size() === 0) {
        日志("本次没有选中路径。");
        return;
    }
    for (var 序号 = 0; 序号 < 路径列表.size(); 序号++) {
        日志(路径列表.get(序号)); // 在这里处理用户确认的路径。
    }
});
// 这里会继续执行，不代表用户已经选好了文件。
```


### 显示(回调, 配置)

> 打开文件选择窗口，等用户确认后把选择结果交给回调。
> 
> 输入回调类型为 FcResultCallback；脚本可以传入一个普通函数。函数接收 List&lt;String&gt;，即装有文件或目录路径字符串的 Java 列表。
> 返回类型为 void，没有同步返回的路径。用户点击确定时才调用回调；取消不会调用这个结果回调。
> 回调在界面操作中触发，应避免在里面执行长时间阻塞任务。
> 需要悬浮窗权限；缺少时提示后直接返回。底层发现缺少存储权限时会发起权限申请并返回，授权后需要重新调用显示方法。
> 第二个参数类型为 Object，接受可解析成 FcConfig 的配置，如下例的普通脚本对象。
> 可设置模式、类型、起始路径、根路径和后缀。配置解析后为空会打印提示，不显示窗口；解析过程仍可能抛出异常。
> 中文配置值不为 null 时优先于对应英文值。后缀筛选控制能否勾选，不表示只显示这些文件。

- 参数 : 回调 {FcResultCallback} 用户确定选择时调用的函数，参数为路径字符串列表，函数无需返回值
- 参数 : 配置 {Object} 可解析为 FcConfig 的配置对象
- 版本 : 1.5.8


```javascript
// 请先在设备上完成悬浮窗和存储权限授权。
var 配置 = {
    模式: "多选", // 一次可勾选多个文件。
    类型: "文件", // 选择文件。
    后缀: "jpg,png" // 设置文件勾选条件。
};
$文件选择器.显示(function (路径列表) {
    // Java 列表用 size() 获取数量，用 get() 读取路径。
    if (路径列表 == null || 路径列表.size() === 0) {
        日志("本次没有选中路径。");
        return;
    }
    for (var 序号 = 0; 序号 < 路径列表.size(); 序号++) {
        日志(路径列表.get(序号)); // 在这里处理用户确认的路径。
    }
}, 配置);
// 这里会继续执行，不代表用户已经选好了文件。
```
