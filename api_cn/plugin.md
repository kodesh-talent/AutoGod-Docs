# $plugin - 插件系统

- 更新时间:2026-10-22 10:55:50

> 插件系统对象，脚本里叫 $plugin。
> 
> 它可以加载并运行"插件 App"（另一个独立安装的 APK）里提供的功能：主脚本通过包名加载插件，
> 拿到插件暴露出来的对象后，就能直接调用插件里写好的函数。适合把复杂功能打包成独立插件、按需加载。



```javascript
var plugins = $plugin.ls(); //列出本机已安装的插件
```




### 加载(包名)

> 加载插件
> 
> 这是上面 load 方法的中文写法，作用完全一样：按包名加载插件并返回可调用的插件对象。

- 参数 : 包名 {字符串} 要加载的插件 App 的包名
- 返回 : {object} 加载成功后得到的插件对象；失败时返回 null
- 版本 : 1.6.8


```javascript
//加载插件
var 插件对象 = $插件.加载("com.example.myplugin");
//使用自己定义的函数
插件对象.我的函数();
```


### 罗列()

> 获得插件列表
> 
> 这是上面 ls 方法的中文写法，作用完全一样：列出本机已安装的插件。

- 返回 : {AppInfo[]} 已安装插件的信息列表，每项含应用名、包名、图标；没有插件时返回空列表
- 版本 : 1.6.8


```javascript
//罗列所有插件应用
var 插件列表 = $插件.罗列();
//打印信息
for (var i = 0; i < 插件列表.length; i++) {
    var 信息 = 插件列表[i];
    log("应用名:" + 信息.appName);
    log("包名:" + 信息.pkgName);
    //显示图标: 信息.icon;
}
```
