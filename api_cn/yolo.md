# $yolo - 目标检测

- 更新时间:2026-10-22 10:55:52

> 目标检测管理对象（脚本里写作 $yolo），用来创建和管理“AI 认东西”的检测器。
> 
> 它本身不直接检测画面，而是负责：创建检测器（YoloObject）、根据编号找回已创建的检测器、
> 判断某个检测器是否还在、关闭并释放指定的检测器、一键关闭全部。
> 真正的“加载模型、在屏幕/图片上找东西”由创建出来的 YoloObject 去做。
> 
> 典型使用流程：先用 create(版本号) 创建一个检测器对象 → 在这个对象上 init() 加载模型 →
> 用 detect() 在屏幕或图片上找目标 → 用完用 close(编号) 释放。
> 模型文件、模型版本和设备运行库必须匹配；检测速度与精度取决于模型和设备性能。



```javascript
// 首选创建一个检测器对象（版本号按你的模型来，比如 12）
var model = $yolo.create(12);
// 之后就可以在 model 上加载模型、做检测了
```




### 创建(版本号)

> 创建目标检测对象（中文方法名版本，作用和 create 完全一样）。
> 
> 这是 create() 的中文别名：按模型版本号创建一个检测器对象，之后再 init() 加载模型、detect() 检测。

- 参数 : 版本号 {整数} 模型版本号（例如 12）
- 返回 : {YoloObject} 新创建的目标检测对象
- 版本 : 1.8.3


```javascript
//首选创建一个对象
var 检测对象 = $目标检测.创建(12);
//接下来就可以设置一些基础配置了
检测对象.初始化("res/yolo.bin", "res/yolo.param", "res/label.txt"); //加载模型
检测对象.设置尺寸(192,64);//注意尺寸必须是32的倍数
检测对象.设置相似度(0.5);//设置相似度
```


### 有(id)

> 判断某个编号对应的检测器是否还在（中文方法名版本，作用和 has 完全一样）。
> 
> 这是 has() 的中文别名：传进检测器编号，返回 true 表示还在，false 表示已关闭或不存在。

- 参数 : id {字符串} 检测器的唯一编号（用 yolo.获取id() 获得）
- 返回 : {布尔值} 该编号对应的检测器还存在返回 true，否则返回 false
- 版本 : 1.8.3


```javascript
var yolo = $yolo.create(12);
var id = yolo.getId();           //先拿到编号
log($目标检测.有(id));            //true
```


### 获取(id)

> 根据编号取回之前创建好的检测器对象（中文方法名版本，作用和 get 完全一样）。
> 
> 这是 get() 的中文别名：常用于跨脚本共享检测器——一个脚本创建并把编号存进 $storage，
> 另一个脚本用编号取回同一个检测器。找不到时返回 null。

- 参数 : id {字符串} 之前创建出来的检测器编号（用 检测对象.获取id() 获得）
- 返回 : {YoloObject} 编号对应的检测器对象；找不到则返回 null
- 版本 : 1.8.3


```javascript
//[初始化脚本.js]:
var storage = $storage.create("我的YOLO");
var 检测对象 = $目标检测.创建(12);
检测对象.初始化("res/yolo.bin", "res/yolo.param", "res/label.txt");
storage.put("mYoloId", 检测对象.获取id()); //把编号存起来
//[其他脚本.js]:
var storage = $storage.create("我的YOLO");
var id = storage.getStr("mYoloId", "null"); //读出编号
var 检测对象 = $目标检测.获取(id);          //按编号取回检测器
```


### 关闭(id)

> 关闭并释放指定编号的检测器（中文方法名版本，作用和 close 完全一样）。
> 
> 这是 close() 的中文别名：按编号关闭检测器、释放内存，并从管理表移除。编号不存在则什么也不做。

- 参数 : id {字符串} 要关闭的检测器编号（用 检测对象.获取id() 获得）
- 版本 : 1.8.3


```javascript
var yolo = $目标检测.创建(12); //创建检测器
//拿到id
var id = yolo.获取id();
//...用 yolo 做检测...
$目标检测.关闭(id); //用完关闭
```


### 关闭所有()

> 一次性关闭所有检测器（中文方法名版本，作用和 closeAll 完全一样）。
> 
> 这是 closeAll() 的中文别名：遍历并释放所有检测器，清空管理表。

- 版本 : 1.8.3


```javascript
// 脚本结束前，统一关掉所有检测器
$目标检测.关闭所有();
```
