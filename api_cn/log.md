# $log - 日志框架

- 更新时间:2026-10-22 10:55:49

> 日志工具对象，脚本里叫 $log。
> 
> 不同级别（信息/调试/警告/错误）的日志会用不同颜色或标签区分。
> 



```javascript
$log.info("task started");
```




### 信息(数据)

> 打印信息日志

- 参数 : 数据 {数据...} 要打印的内容，可传多个参数，会依次拼接
- 版本 : 1.7.0


```javascript
$日志.信息("信息");
```


### 调试(数据)

> 打印调试日志

- 参数 : 数据 {数据...} 要打印的调试内容，可传多个参数
- 版本 : 1.7.0


```javascript
$日志.调试("调试");
```


### 警告(数据)
