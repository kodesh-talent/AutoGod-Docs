# MenuItem - 悬浮按钮

- 更新时间:2026-10-22 10:55:53

> 悬浮球上的一个圆形小按钮（MenuItem）。
> 
> 一个悬浮球里只有一个容器（MenuBody），但容器里可以放多个按钮。容器负责展开/收起动画，
> 按钮负责具体功能（点一下干什么）。用 $arc.item(图标) 创建一个按钮，用 样式/背景/图标颜色 等
> 方法把它打扮好看，再用 点击(...) 绑上要做的事，最后添加到容器里。所有设置方法都返回自己，可链式。



```javascript
var item = $arc.item("ic_settings");          //创建一个设置图标按钮
item.样式("outline").背景("#FF222222");        //设置样式和背景
item.click(function(clicked) {                 //点它要做的事
    log("点了设置按钮");
});
```




### 样式(样式)

> 选择按钮的预设外观样式（中文写法）。
> 
> 和 style 完全一样，只是方法名是中文。先定样式再调颜色、圆角等外观。

- 参数 : 样式 样式名：default、outline、tonal，也可用对应中文（边框/轮廓/色调）
- 返回 : 当前按钮自己，可继续链式设置
- 版本 : 1.6.9


```javascript
var 小按钮 = $arc.item("ic_settings").样式("边框");
小按钮.背景("#55222222").图标颜色("#FFFFFFFF");
```


### 点击(点击事件)

> 设置点这个按钮时要执行的函数（中文写法）。
> 
> 和 click 完全一样，只是方法名是中文。

- 参数 : 点击事件 点击时执行的函数，形如 function(被点的按钮) {}；传 null 清除
- 返回 : 当前按钮自己，可继续链式设置
- 版本 : 1.6.9


```javascript
var 小按钮 = $arc.item("ic_settings");
小按钮.点击(function(被点的按钮) {
    log("宽度=" + 被点的按钮.获取宽度());
});
```


### 涟漪(颜色字符串)

> 设置点按钮时那圈水波涟漪的颜色（中文写法，颜色字符串）。
> 
> 和 ripper(字符串) 完全一样，只是方法名是中文。

- 参数 : 颜色字符串 涟漪颜色，例如 "#66FF0000"
- 返回 : 当前按钮自己，可继续链式设置
- 版本 : 1.6.9


```javascript
var 小按钮 = $arc.item("ic_settings").涟漪("#66FF0000");
```


### 涟漪(颜色值)

> 设置点按钮时那圈水波涟漪的颜色（中文写法，颜色整数）。
> 
> 和 ripper(整数) 完全一样，只是方法名是中文。

- 参数 : 颜色值 ARGB 颜色整数
- 返回 : 当前按钮自己，可继续链式设置
- 版本 : 1.6.9


```javascript
var 小按钮 = $arc.item("ic_settings").涟漪($颜色.红色);
```

### 弧度(弧度)

> 把按钮四个角都设成同样的圆角大小（中文写法）。
> 
> 和 radius 完全一样，只是方法名是中文。单位像素，给很大数值就变成圆按钮。

- 参数 : 弧度 圆角大小，单位像素
- 返回 : 当前按钮自己，可继续链式设置
- 版本 : 1.6.9


```javascript
var 小按钮 = $arc.item("ic_settings").弧度(12);
```


### 图标(资源名称)

> 设置或换成按钮上显示的图标（中文写法）。
> 
> 和 icon 完全一样，只是方法名是中文。

- 参数 : 资源名称 内置图标名或本地图片路径

### 获取宽度()

> 读取这个按钮实际显示出来的宽度（中文写法）。
> 
> 和 getW 完全一样，只是方法名是中文。要等按钮显示后再读，不然通常是 0。

- 返回 : 按钮宽度，单位像素
- 版本 : 1.6.9


```javascript
var 小按钮 = $arc.item("ic_settings");
小按钮.点击(function() {
    log("宽度=" + 小按钮.获取宽度() + " px");
});
$arc.body("tools").添加($arc.item("ic_menu")).添加(小按钮).显示();
```
