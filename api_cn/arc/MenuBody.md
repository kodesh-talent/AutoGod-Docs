# MenuBody - 按钮容器

- 更新时间:2026-10-22 10:55:53

> 悬浮球菜单的按钮容器（MenuBody）。
> 
> 它是一个“圆盘”：屏幕上有一个可以拖动的主按钮，点一下，周围会展开一圈小按钮，再点一下又收回去。
> 用 $arc.body(名字) 创建一个容器，然后用 添加() 往里放按钮——第一个放进去的就是主按钮，
> 之后放的都是展开后才出现的小按钮，最后调 显示() 把它显示到屏幕上。



```javascript
var 菜单 = $arc.body("tools");                 //创建一个名为 tools 的容器
菜单.添加($arc.item("ic_menu"));               //第一个按钮成为主按钮
菜单.添加($arc.item("ic_settings"));           //后续按钮是展开后的小按钮
菜单.显示();                                   //显示悬浮球
```




### 添加(小按钮)

> 往这个菜单容器里加一个按钮（中文写法）。
> 
> 和 add 完全一样，只是方法名是中文。第一个加进去的是主按钮，之后的是展开后出现的小按钮。

- 参数 : 小按钮 要加进去的按钮，用 $arc.item(图标) 创建
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.6.9


```javascript
var 菜单 = $arc.body("tools");
菜单.添加($arc.item("ic_menu"));      //主按钮
菜单.添加($arc.item("ic_settings"));  //展开后出现的小按钮
菜单.显示();
```


### 显示()

> 把这个悬浮球菜单真正显示到屏幕上（中文写法）。
> 
> 和 show 完全一样，只是方法名是中文。要先加好按钮再调它。

- 版本 : 1.6.9


```javascript
var 菜单 = $arc.body("tools");
菜单.添加($arc.item("ic_menu"));
菜单.添加($arc.item("ic_settings"));
菜单.显示();
```


### 名称(名称)

> 给这个菜单起一个唯一的名字（中文写法）。
> 
> 和 name 完全一样，只是方法名是中文。要在 显示() 之前设置。

- 参数 : 名称 菜单的唯一名字
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.6.9


```javascript
var 菜单 = $arc.body("tools").名称("tools-menu");
菜单.添加($arc.item("ic_menu")).显示();
```


### 边距(左贴边边距, 右贴边边距)

> 设置主按钮贴到屏幕左、右边缘时，离屏幕边保留的距离（中文写法）。
> 
> 和 margin 完全一样，只是方法名是中文。单位是像素。

- 参数 : 左贴边边距 贴到屏幕左边时保留的像素距离，默认 0
- 参数 : 右贴边边距 贴到屏幕右边时保留的像素距离，默认 0
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.6.9


```javascript
var 菜单 = $arc.body("tools").边距(16, 24);
```


### 半径(半径)

> 设置小按钮从主按钮向外展开的距离（展开半径，中文写法）。
> 
> 和 radius 完全一样，只是方法名是中文。单位 dp，默认 80。

- 参数 : 半径 展开半径，单位 dp
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.6.9


```javascript
var 菜单 = $arc.body("tools").半径(96);
```


### 全局显示(是否全局显示)

> 设置回到手机桌面后，这个悬浮球还继不继续显示（中文写法）。
> 
> 和 global 完全一样，只是方法名是中文。默认 true 继续显示，传 false 则退后台就隐藏。

- 参数 : 是否全局显示 退到后台后是否继续显示，默认 true
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.6.9


```javascript
var 菜单 = $arc.body("tools").全局显示(false);
```

> 
> 和 dur 完全一样，只是方法名是中文。单位毫秒，默认 250。
