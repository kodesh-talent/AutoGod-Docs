# $touch - 触摸驱动

- 更新时间:2026-10-22 10:55:52

> $touch：基于无障碍服务的触摸驱动，用来模拟手指点击、长按、滑动和按键。
> 
> 它通过 C/C++ 层注入触摸事件，速度较快。使用前要先确认无障碍权限已开启、再 init 初始化，
> 之后才能做点击滑动。适合做不需要 Root 的手势模拟。



```javascript
// 标准用法：先检查权限、初始化，再点击
if ($touch.hasPermit()) {
    $touch.init();
    $touch.click(320, 640);
}
```




### 有权限()

> 是否可用：检查触摸注入权限是否就绪。
> 
> 这是 $touch.hasPermit 的中文叫法。

- 返回 : {布尔值} true 表示权限就绪
- 版本 : 1.7.0


```javascript
if ($触摸.有权限()) {
    $触摸.初始化();
}
```


### 初始化()

> 初始化：准备触摸注入。
> 
> 这是 $touch.init 的中文叫法。

- 返回 : {布尔值} true 表示成功


```javascript
var ok = $触摸.初始化();
log("初始化结果：" + ok);
```


### 触摸按下(手指ID, x, y)

> 触摸按下：指定手指在某点按下。
> 
> 这是 $touch.touchDown 的中文叫法。

- 参数 : 手指ID {整数} 手指编号
- 参数 : x {整数} 横坐标
- 参数 : y {整数} 纵坐标
- 版本 : 1.7.0


```javascript
$触摸.触摸按下(0, 100, 100);
```


### 触摸移动(手指ID, x, y)

> 触摸移动：把按下的手指移到新位置。

> 这是 $touch.touchMove 的中文叫法。

- 参数 : x {整数} 新横坐标
- 参数 : y {整数} 新纵坐标
