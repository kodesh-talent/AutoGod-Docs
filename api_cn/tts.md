# $tts - 语音阅读

- 更新时间:2026-10-22 10:55:52

> 语音朗读（文字转语音，TTS）对象，脚本里叫 $tts。
> 
> 它能让手机"开口说话"：把一段文字念出来给你听，常用于自动化脚本里做语音提示、播报结果。
> 朗读是异步进行的——调用方法后立刻返回，声音在后台慢慢念，脚本不会卡住等待念完。



```javascript
$tts.read("Hello");  //让手机念出这句话
```




### 阅读(文本, 配置)

> 播放文本(配置)
> 
> 这是上面 read 方法的中文写法，作用完全一样：按自定义配置朗读一段文字。
> 配置对象里可用中文字段：速度、音调、音量、语言、类型（与英文 rate/pitch/volume/language/streamType 对应）。

- 参数 : 文本 {字符串} 要朗读出来的文字内容
- 参数 : 配置 {对象} 朗读配置，可含 速度/音调/音量/语言/类型 字段；传 null 则用默认配置
- 版本 : 1.6.9


```javascript
var 配置 = {
    速度: 1,        //语速，1 是正常
    音调: 1,        //音调，1 是正常
    音量: 1,        //音量，1 是正常
    语言: "zh",     //用中文朗读
    类型: "music"   //出声通道，媒体音乐
};
$语音.阅读("你好呀，早安~", 配置);
```


### 阅读(文本)

> 播放文本
> 
> 这是上面 read(text) 的中文写法，作用完全一样：只用默认配置朗读一段文字。

- 参数 : 文本 {字符串} 要朗读出来的文字内容
- 版本 : 1.6.9


```javascript
$语音.阅读("你好呀，早安~");
```
