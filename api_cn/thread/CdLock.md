# CdLock - 倒计时锁

- 更新时间:2026-10-22 10:55:51

> 倒计时锁对象（脚本里用 $thread.newCdLock(次数) 得到）。
> 
> 它像一个“计数器加一个等待点”：创建时给它一个数字 N，表示要等 N 件事都做完。
> 每件事做完就调用一次 ok()（计数器减 1）；主线程调用 finish() 会卡在那里一直等，
> 直到计数器减到 0 才继续往下走。
> 
> 新手提示：它适合“我要等好几件后台任务都完成，再做下一步”的场景。
> 例如创建锁时传 2，就表示要等 2 次 ok() 后 finish() 才放行。



```javascript
//创建一个倒计时锁，要等 2 件事做完
var lock = $thread.newCdLock(2);
//启动两个后台线程分别干活
$thread.run(function () {
    sleep(1000);       //第一件事干 1 秒
    lock.ok();          //做完一件，计数器减 1
});
$thread.run(function () {
    sleep(2000);       //第二件事干 2 秒
    lock.ok();          //做完一件，计数器减 1
});
log("主线程在这里等两件事都做完...");
lock.finish();          //卡住等待，直到两次 ok() 都调用完
log("两件事都做完了，继续往下");
```




### 完成()

> 报告一件任务已经完成。
> 
> 倒计时锁由 $线程.新建倒计时锁(数量) 创建，返回 CdLock 对象。
> 创建时的数量表示需要收到多少次完成通知；每通知一次就减一，减到零后不会变成负数。
> 输入：无参数。输出：void，表示只通知计数器，不返回数据。
> 同一件任务只通知一次；不要为了跳过等待而多调用，否则会把尚未完成的任务也算作完成。

- 版本 : 1.8.3


```javascript
var 倒计时锁 = $线程.新建倒计时锁(2); //一共需要完成两件任务
倒计时锁.完成(); //第一件任务完成，剩余数量从二变为一
日志("还剩：" + 倒计时锁.获取数量());
倒计时锁.完成(); //第二件任务完成，剩余数量变为零
倒计时锁.结束(); //此时已归零，立即继续执行
日志("两件任务都已完成");
```


### 结束()

> 等待倒计时锁归零。
> 
> 倒计时锁由 $线程.新建倒计时锁(数量) 创建，返回 CdLock 对象。
> 创建时的数量表示需要收到多少次完成通知；每通知一次就减一，减到零后不会变成负数。
> 输入：无参数。输出：void，没有可读取的返回值。
> 调用会阻塞当前执行它的线程，并不是只阻塞某个固定的主线程。
> 只有计数归零才继续；不要在界面线程使用，也不要让负责通知完成的同一线程先进入等待。
> 等待被中断时会抛出运行异常；如果担心任务遗漏完成通知，可改用带超时时间的重载。

- 版本 : 1.8.3


```javascript
var 倒计时锁 = $线程.新建倒计时锁(1); //只等待一件后台任务
$线程.运行(function () { //创建并立即启动，任务才会真正执行
    try {
        等待(100); //模拟一小段耗时工作
    } finally {
        倒计时锁.完成(); //无论任务是否发生异常，都通知这件任务已经结束
    }
});
倒计时锁.结束(); //在脚本工作线程等待，不要放到界面回调中
日志("后台任务已结束；是否成功需要由任务另行记录");
```


### 结束(超时时间)

> 等待倒计时锁归零。
> 
> 倒计时锁由 $线程.新建倒计时锁(数量) 创建，返回 CdLock 对象。
> 创建时的数量表示需要收到多少次完成通知；每通知一次就减一，减到零后不会变成负数。
> 输入：long 类型的超时时间，单位为毫秒；1000 毫秒是一秒。
> 输出：boolean 布尔值，true 表示返回时已经归零，false 表示等待超时且仍有未完成任务。
> 超时只结束本次等待，不会取消后台任务，也不会自动减少计数。零或负数不会继续等待。
> 本方法会阻塞当前线程；等待被中断时会抛出运行异常，不要在界面线程中使用。

- 参数 : 超时时间 {long} 最长等待时间，单位为毫秒；零或负数仅检查当前是否完成
- 返回 : {boolean} 计数是否已归零；真值表示完成，假值表示超时
- 版本 : 1.8.3


```javascript
var 倒计时锁 = $线程.新建倒计时锁(1); //先准备一个尚未完成的任务
var 是否完成 = 倒计时锁.结束(100); //最多等一百毫秒，本例没有通知完成，所以会超时
if (!是否完成) {
    日志("还没有完成，稍后可以再次等待");
}
倒计时锁.完成(); //模拟稍后收到任务完成通知
日志("再次检查：" + 倒计时锁.结束(0)); //已归零，立即返回真值
```


### 获取数量()

> 读取尚未完成的任务数量。
> 
> 倒计时锁由 $线程.新建倒计时锁(数量) 创建，返回 CdLock 对象。
> 创建时的数量表示需要收到多少次完成通知；每通知一次就减一，减到零后不会变成负数。
> 输入：无参数。输出：long 长整数，表示尚需收到的完成通知数量。
> 这里只读取当前数量，不会等待，也不会减少数量；后台任务可能在读取后继续改变计数。

- 返回 : {long} 尚未完成的任务数量，最小为零
- 版本 : 1.8.3


```javascript
var 倒计时锁 = $线程.新建倒计时锁(2); //先准备两件任务
日志("开始时：" + 倒计时锁.获取数量()); //此时为二
倒计时锁.完成(); //通知其中一件已完成
日志("通知一次后：" + 倒计时锁.获取数量()); //此时为一
倒计时锁.完成(); //通知另一件已完成
日志("全部通知后：" + 倒计时锁.获取数量()); //此时为零
```
