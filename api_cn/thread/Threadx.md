# Threadx - 增强线程

- 更新时间:2026-10-22 10:55:52

> 增强线程对象（脚本里用 $thread.create(function(){...}) 得到）。
> 
> 普通脚本是“从上往下一行行跑”的，遇到 sleep 或联网就会卡住。
> 线程的作用就是“另起一条路同时干活”：你把要在后台做的事写成一个 function 交给 $thread.create，
> 它只会准备好任务；调用返回对象的 start() 后才在后台执行，不耽误脚本工作线程继续。
> 
> 这个对象比普通线程多带了几个“小格子”（字符串、布尔、整数、长整数、对象标志位），
> 方便主线程和后台线程之间互相递一点数据：主线程 setXxx 写进去，后台线程 getXxx 读出来。
> 需要请求中断时调用 kill()；后台任务是否退出取决于它是否响应中断。



```javascript
//创建一个后台线程，里面写要在后台做的事
var tx = $thread.create(function () {
    log("后台线程开始干活");
    sleep(2000);            //后台里睡 2 秒
    log("后台线程干完了");
});
tx.start();              //准备完成后启动线程，只能启动一次
log("主线程没有被卡住，继续往下走");
log("这个线程的名字是：" + tx.name());
```




### 名称()

> 读取线程的名字，方便区分不同任务。
> 输入：无参数。输出：String 字符串，即这个线程当前的名字。
> 可通过 $线程.创建(名字, 任务回调) 创建命名线程；名字与另外存放的字符串标志不是同一项数据。

- 返回 : {String} 线程当前的名字
- 版本 : 1.7.0


```javascript
var 线程对象 = $线程.创建("名称演示", function () {}); //只创建，本例不需要运行任务
日志("线程名字：" + 线程对象.名称()); //读取创建时指定的名字
```


### 是运行的()

> 读取线程的中断标记；不要把这个方法当成“正在运行”的判断。
> 输入：无参数。输出：boolean 布尔值，true 只表示当前中断标记已设置，false 表示当前未设置。
> 当前实现读取的是中断状态。尚未启动、正常结束或中断标记被清除，都可能读到 false；true 也不能证明任务已结束。
> 方法名字容易产生误解，不能据此决定是否再次启动线程；同一个线程对象只能启动一次。

- 返回 : {boolean} 当前的中断标记，并非运行状态
- 版本 : 1.7.0


```javascript
var 线程对象 = $线程.创建(function () {}); //创建对象，暂时不启动
日志("当前中断标记：" + 线程对象.是运行的()); //这里只观察标记，不判断任务是否运行
```


### 设置字符串(str)

> 保存线程携带的字符串标志。
> 它像放在线程对象里的一个数据格子，可先写入，再由任务或脚本工作线程读取。
> 命名构造方式默认保存传入的名字；未命名构造方式默认保存自动生成的文字标记，该标记不等于线程名。
> 单次读写由原子容器保存，但多个操作连起来并不自动变成一个不可分割的步骤。
> 输入：String 类型的文字。输出：void，只保存数据，不返回数据。

- 参数 : str {String} 要保存的文字；读取时使用 获取字符串()
- 版本 : 1.7.0


```javascript
var 线程对象 = $线程.创建(function () {}); //先取得增强线程对象，读写数据格子不需要启动
线程对象.设置字符串("准备完成"); //将示例数据放入对应格子
var 读取结果 = 线程对象.获取字符串(); //使用配对的读取方法取出数据
日志("读取结果：" + 读取结果); //把值转为说明文字后输出
```

### 停止()

> 向线程发出中断请求。
> 输入：无参数。输出：void，没有返回数据，也不保证调用结束时后台任务已经退出。
> 它调用线程的中断功能，不会强制杀死任意代码，也不会自动修改布尔标志。
> 任务应主动检查退出开关；全局 sleep 和等待会等足本次时长，收到中断也不提前返回。不要把无限循环当作一定能被强行停止的任务。

- 版本 : 1.7.0


```javascript
var 线程对象 = $线程.创建(function () {
    while (线程对象.获取布尔()) { //每轮检查是否还需要继续
        try {
            等待(100); //每轮暂停，避免持续占用处理器
        } catch (异常) { //等待收到异常时退出本次后台任务
            break;
        }
    }
});
线程对象.start(); //这是继承的线程启动方法，没有中文别名，只调用一次
等待(300); //让后台任务运行一小段时间
线程对象.设置布尔(false); //先通知循环不要开始下一轮
线程对象.停止(); //再发出中断请求；示例的全局等待仍会等足本次时长
```
