# $tip - 阻塞式对话框

- 更新时间:2026-10-22 10:55:52

> $tip：一系列会"卡住脚本"的弹窗工具。
> 
> 包括信息提示、输入框、整数输入、确认框、自定义布局、单选/多选列表、日期和时间选择。
> 调用这些方法后脚本会暂停，等用户在弹窗里操作完（点确定/取消/选好）才继续往下跑，
> 所以很适合做"需要用户确认一步再走下一步"的顺序流程。



```javascript
// 弹一个提示框，脚本会等用户关闭后再继续
$tip.show("Notice", "Task completed");
```




### 信息(信息)

> 信息对话框：弹出标题为"信息"的提示框。
> 
> 这是 $tip.i 的中文叫法。

- 参数 : 信息 {Object...} 要显示的内容
- 版本 : 1.7.0


```javascript
// 弹出信息框
$tip.信息("我是信息");
```

### 输入(标题, 回调)

> 输入对话框：弹框让用户输入文字，结果走回调。
> 
> 这是 $tip.input 的中文叫法。

- 参数 : 标题 {字符串} 对话框标题
- 参数 : 回调 {function(value){}} 输入完成回调
- 版本 : 1.7.0


```javascript
$tip.输入("请输入你的名字", function(数据) {
    toast("你输入的是：" + 数据);
});
```

### 显示(标题, 视图)

> 自定义对话框：把 $ui 布局出来的视图塞进弹窗。
> 
> 这是 $tip.show(标题,视图) 的中文叫法，右上角有关闭。

- 参数 : 标题 {字符串} 对话框标题
- 参数 : 视图 {View} $ui 加载的视图
- 版本 : 1.7.0


```javascript
var ui = $ui.layout("ag-app-example/$tip - 阻塞式对话框/01.自定义对话框/ui.xml");
var 视图 = ui.getView();
$tip.显示("自定义对话框", 视图);
```

### 选择日历(回调)

> 日期选择对话框（日历样式）：选年月日。
> 
> 这是 $tip.calendar 的中文叫法，回调在子线程。

- 参数 : 回调 {function(dateInfo){}} 选完日期回调，含 year/month/day
- 版本 : 1.7.0


```javascript
$tip.选择日历(function(信息) {
    var 年 = 信息.year;
    var 月 = 信息.month;
    var 日 = 信息.day;
    toast(年 + "-" + 月 + "-" + 日);
});
```
