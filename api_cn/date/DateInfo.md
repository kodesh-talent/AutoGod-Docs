# DateInfo - 日期信息

- 更新时间:2026-10-22 10:55:46

> 日期信息快照，由 $date.info() 或 $日期.信息() 返回。
> 对象把同一时刻拆成年、月、日、星期、时、分、秒、毫秒等部分，按设备默认时区计算。
> 创建后不会随时钟自动更新，想看最新时间需要再次获取信息。
> 英文和中文字段在创建时填入相同数值，但它们是独立字段；不要手动修改其中一项后认为其他项也会自动改变。
> 字符串解析可能失败并返回 null，先判断不为空，再读取其中的内容。



```javascript
var info = $date.info(); //取得现在这一刻的快照
log("日期：" + info.year + "-" + info.month + "-" + info.day);
log("时间戳：" + info.getStamp()); //通过方法读取长整数
var names = ["", "星期日", "星期一", "星期二", "星期三", "星期四", "星期五", "星期六"];
log("星期：" + names[info.week]); //按本类的一至七编号转换成文字
var other = $date.info("2026-01-02 03:04:05"); //解析指定时间
if (other != null) {
    log("指定时间的小时：" + other.getHour());
}
```




### const {long} 时间戳;

> 保存时间戳信息。
> 属性类型：long。距离协调世界时一九七零年一月一日零点的毫秒数；这不是秒数。
> 日期信息按设备默认时区拆分，是获取时的快照；读取它不会再次查询系统时间。
> 创建时中英文字段同时填入同一值，但直接赋值不会同步其他字段，也不会修改手机时间。建议将本对象作为结果只读使用。


```javascript
var 日期信息 = $日期.信息("2026-01-02 03:04:05"); //解析一个格式明确的时间
if (日期信息 != null) { //解析成功后才能访问结果
    日志("时间戳：" + 日期信息.时间戳); //读取属性值
    日志("通过方法读取：" + 日期信息.获取时间戳()); //正常获取且未手动改值时，两种读取方式一致
} else {
    日志("日期解析失败，请检查输入格式");
}
```

### json()

> 把当前快照转换为带换行的对象数据文本。
> 输入：无参数。输出：String 字符串；序列化失败时可能返回 null。
> 文本同时包含英文和中文字段，适合日志展示。返回的是文字，不是可直接读取 year 属性的新对象。

- 返回 : {String} 当前对象的格式化数据文本；序列化失败时为 null


```javascript
var info = $date.info(); //先取得日期信息对象
var text = info.json(); //将快照序列化为文字
if (text != null) {
    log("完整信息：" + text); //可看到英文和中文各组字段
}
```
