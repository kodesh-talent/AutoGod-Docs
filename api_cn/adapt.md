> 全局坐标适配器，用项目中的屏幕配置描述设计分辨率，并换算脚本坐标和图片尺寸。
> 
> 作用是让同一份脚本和图片素材，能在不同分辨率的手机上都跑得准：
> 你在"开发机"上按一套分辨率写好坐标、裁好图，到了用户手机上，$adapt 会按屏幕差异自动把坐标和图片
> 等比例换算过去，不用为每款手机单独调。需要先在项目里配置好开发时的屏幕宽高、dpi 等信息。



```javascript
var x = $adapt.getPx(480); //把开发机上的 480 像素，换算成当前手机上的实际像素
log("换算后坐标：" + x);
```
