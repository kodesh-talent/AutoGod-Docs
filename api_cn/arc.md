# $arc - 悬浮球

- 更新时间:2026-10-22 10:55:45

> 悬浮球（扇形悬浮菜单）对象，脚本里叫 $arc。
> 
> 一个"容器"负责显示和关闭一组按钮，按钮用 item 创建后装进容器。
> 



```javascript
var item = $arc.item("logo_ag");
$arc.body("工具菜单").add(item).show();
```

### 按钮(图标路径)

> 创建悬浮按钮
> 
> 这是上面 item 方法的中文写法，作用完全一样：先创建一个带图标的小按钮。
> 
> 容器可以装多个悬浮按钮，并且可以显示出来。
> 
> 而悬浮按钮中每个按钮都有不一样的样式，所以悬浮按钮用来控制自身的样式。

- 参数 : 图标路径 {字符串} 图标：内置图标资源名，或本地自定义图片的相对路径
- 返回 : {MenuItem} 创建好的悬浮按钮对象，之后用容器的添加方法装进去
- 版本 : 1.6.9


```javascript
//创建悬浮小按钮,可以被容器添加进去
var 按钮1 = $悬浮球.按钮("logo_ag"); //内置图标资源名或本地图片路径
//之后可以创建容器并且显示，例如：
$悬浮球.容器("悬浮球1号").添加(按钮1).显示();
//如果有多个悬浮小按钮：
var 按钮01 = $悬浮球.按钮("logo_ag");
var 按钮02 = $悬浮球.按钮("ic_color");
$悬浮球.容器("悬浮球2号").添加(按钮01).添加(按钮02).显示();
```


### 容器(容器名称)

> 创建容器
> 
> 容器主要用来控制显示和关闭的，它可以装入多个悬浮按钮，之后显示出来。
> 
> 需要注意：如果悬浮球菜单已经存在了，那么将无法显示第二个名称相同的悬浮球。

- 参数 : 容器名称 {字符串} 这个悬浮菜单容器的名字，用来区分和关闭
- 返回 : {MenuBody} 创建好的菜单容器对象，之后用 添加 装按钮、显示 显示出来
- 版本 : 1.6.9


```javascript
//创建悬浮按钮容器,用于存放多个小按钮，并且显示
var 容器 = $悬浮球.容器("悬浮球1号");//指定一个名称，方便后面根据名称关闭
//添加一个按钮并且显示，例如：
var 按钮 = $悬浮球.按钮("logo_ag");
容器.添加(按钮).显示();
```


### 有(容器名称)

> 判断悬浮球是否存在

- 参数 : 容器名称 {字符串} 要检查的悬浮菜单容器名字
- 返回 : {布尔值} 该名字的悬浮菜单当前正在显示就返回 true，否则返回 false
- 版本 : 1.6.9


```javascript
if ($悬浮球.有("悬浮球1号")){
    信息("悬浮球1号存在");
}
```


### 关闭(悬浮球名称)

> 关闭
> 
> 根据容器的名称来关闭容器

- 参数 : 悬浮球名称 {字符串} 要关闭的悬浮菜单容器名字
- 版本 : 1.6.9


```javascript
$悬浮球.关闭("悬浮球1号");
```


### 关闭所有()

> 关闭全部
> 
> 将所有创建的悬浮球都关闭掉

- 版本 : 1.6.9


```javascript
//关闭全部悬浮球(容器)
$悬浮球.关闭所有();
```
