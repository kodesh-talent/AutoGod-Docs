# $res - 资源管理器

- 更新时间:2026-10-22 10:55:50

> 资源管理器（脚本里直接用 $res 或 $资源）。
> 
> 它像一个“小记事本”：你可以把一些数据（一段文字、一个数字、一个真假值）起个名字存进去，
> 下次再按名字取出来。这些数据会被持久化保存，脚本关掉再打开还在。
> 
> 使用步骤：先 create("名字") 得到一个资源本，再 set 存数据、get 取数据。
> 资源可以跨线程访问，但它不是外部文件系统，别把它当普通文件夹用。



```javascript
//创建一本名为“我的资源”的资源本
var res = $res.create("我的资源");
//存一条数据：名字叫“名字”，内容是“张三”
res.set("名字", "张三");
//再按名字取出来
log("取出的名字是：" + res.get("名字"));
```




### 创建(名称)

> 创建一本资源本（中文方法名“创建”）。
> 
> 和 create() 是同一个功能，只是方法名用中文。

- 参数 : 名称 {String} 资源本的名字
- 返回 : {AgRes} 资源本对象
- 版本 : 1.6.9


```javascript
var res = $res.创建("我的资源");
log("资源本创建好了");
```


### 设置(名称, 数据)

> 往资源本里存一条数据（中文方法名“设置”）。
> 
> 和 set() 是同一个功能，只是方法名用中文。同名会被覆盖。

- 参数 : 名称 {String} 这条数据的名字
- 参数 : 数据 {Object} 要存的内容
- 版本 : 1.6.9


```javascript
var res = $res.create("我的资源");
res.设置("名字", "张三");
res.设置("年龄", 18);
log("数据已保存");
```


### 获取(名称)

> 按名字从资源本里取一条数据（中文方法名“获取”）。
> 
> 和 get() 是同一个功能，只是方法名用中文。名字不存在时返回 null。

- 参数 : 名称 {String} 要取的数据的名字
- 返回 : {Object} 这条数据的内容；不存在时返回 null
- 版本 : 1.6.9


```javascript
var res = $res.create("我的资源");
res.set("名字", "张三");
var name = res.获取("名字");
log("取出的名字是：" + name);
```


### 获取(名称, 默认值)

> 按名字取一条文字数据，没有就返回默认文字（中文方法名“获取”）。
> 
> 和 get(名字, 默认文字) 是同一个功能，只是方法名用中文。

- 参数 : 名称 {String} 要取的数据的名字
- 参数 : 默认值 {String} 没有这条数据时返回的默认文字
- 返回 : {String} 取出的文字，或默认文字
- 版本 : 1.6.9


```javascript
var res = $res.create("我的资源");
var name = res.获取("姓名", "张三");
log("姓名是：" + name);
```


### 获取(名称, 默认值)

> 按名字取一个小数数据，没有就返回默认小数（中文方法名“获取”）。
> 
> 和 get(名字, 默认小数) 是同一个功能，只是方法名用中文。

- 参数 : 名称 {String} 要取的数据的名字
- 参数 : 默认值 {float} 没有时返回的默认小数
- 返回 : {float} 取出的小数或默认小数；不是数字时返回 -1
- 版本 : 1.6.9


```javascript
var res = $res.create("我的资源");
res.set("PI", 3.14);
var pi = res.获取("PI", 0.0);
log("圆周率：" + pi);
```


### 获取(名称, 默认值)

> 按名字取一个整数数据，没有就返回默认整数（中文方法名“获取”）。
> 
> 和 get(名字, 默认整数) 是同一个功能，只是方法名用中文。

- 参数 : 名称 {String} 要取的数据的名字
- 参数 : 默认值 {int} 没有时返回的默认整数
- 返回 : {int} 取出的整数或默认整数；不是数字时返回 -1
- 版本 : 1.6.9


```javascript
var res = $res.create("我的资源");
res.set("age", 18);
var age = res.获取("age", 0);
log("年龄是：" + age);
```


### 获取(名称, 默认值)

> 按名字取一个真假值，没有就返回默认真假值（中文方法名“获取”）。
> 
> 和 get(名字, 默认真假值) 是同一个功能，只是方法名用中文。

- 参数 : 名称 {String} 要取的数据的名字
- 参数 : 默认值 {boolean} 没有时返回的默认真假值
- 返回 : {boolean} 取出的真假值或默认真假值
- 版本 : 1.6.9


```javascript
var res = $res.create("我的资源");
res.set("已登录", true);
var isLogin = res.获取("已登录", false);
if (isLogin) {
    log("已经登录了");
}
```


### 加载(路径)

> 把本地资源文件加载到内部存储（中文方法名“加载”）。
> 
> 和 load() 是同一个功能，只是方法名用中文。返回 true 成功，false 失败。

- 参数 : 路径 {String} 要加载的资源文件路径
- 返回 : {boolean} true 表示成功，false 表示失败
- 版本 : 1.6.9


```javascript
var res = $res.create("我的资源");
var ok = res.加载("res/backup.res");
if (ok) {
    log("加载成功，内容：" + res.查看());
}
```


### 罗列()

> 列出这本资源本里所有数据的名字（中文方法名“罗列”）。
> 
> 和 ls() 是同一个功能，只是方法名用中文。

- 返回 : {List} 所有数据名字的列表
- 版本 : 1.6.9


```javascript
var res = $res.create("我的资源");
res.set("名字", "张三");
var names = res.罗列();
for (var i = 0; i < names.size(); i++) {
    log("第" + i + "条数据叫：" + names.get(i));
}
```


### 查看()

> 把这本资源本的全部内容以一段文字打印出来（中文方法名“查看”）。
> 
> 和 cat() 是同一个功能，只是方法名用中文。

- 返回 : {String} 资源本的全部内容文字
- 版本 : 1.6.9


```javascript
var res = $res.create("我的资源");
res.set("名字", "张三");
log("当前资源内容：" + res.查看());
```


### 下载(保存路径)

> 把资源本内部的数据导出到指定路径（中文方法名“下载”）。
> 
> 和 dump() 是同一个功能：把内部存储的数据拷贝到外部路径。返回保存后的文件路径。

- 参数 : 保存路径 {String} 想保存到的文件路径
- 返回 : {String} 实际保存出来的文件路径
- 版本 : 1.6.9


```javascript
var res = $res.create("我的资源");
res.set("名字", "张三");
var out = res.下载("/sdcard/backup");
log("已导出到：" + out);
```
