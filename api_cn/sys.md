# $sys - 系统工具

- 更新时间:2026-10-22 10:55:51

> $sys：一堆和手机系统有关的小工具。
> 
> 包括飞行模式、音量、设备标识、剪切板读写、电池优化白名单、前台保活、开发者指针等。
> 很多改系统设置的功能需要先拿到"修改系统设置"权限（用 $permit.set()）。



```javascript
// 取一下设备唯一标识
var id = $sys.getDeviceId();
```




### 飞行模式(是否开启)

> 设置飞行模式：打开或关闭。
> 
> 这是 $sys.airplane 的中文叫法；若无法自动改，会引导手动设置。

- 参数 : 是否开启 {布尔值} true 开，false 关
- 版本 : 1.7.0


```javascript
// 打开飞行模式
$sys.飞行模式(true);
```


### 音量(类型, 音量)

> 设置音量：调整某一类声音的大小。
> 
> 这是 $sys.volume 的中文叫法。

- 参数 : 类型 {字符串} 声音类型，如 系统/铃声/音乐/闹钟/通知/电话
- 参数 : 音量 {整数} 目标音量
- 版本 : 1.7.0


```javascript
// 媒体音量拉满
$sys.音量("音乐", 100);
```


### 获取设备标识()

> 获得唯一标识：设备的 MD5 指纹。
> 
> 这是 $sys.getDeviceId 的中文叫法。

- 返回 : {字符串} 设备唯一标识
- 版本 : 1.7.0


```javascript
var 标识 = $sys.获取设备标识();
toast("设备标识：" + 标识);
```


### 有剪切板()

> 判断剪切板是否有内容。
> 
> 这是 $sys.hasClip 的中文叫法。

- 返回 : {布尔值} true 表示有内容
- 版本 : 1.7.0


```javascript
if ($sys.有剪切板()) {
    var 内容 = $sys.获取剪切板();
    toast("剪切板：" + 内容);
}
```


### 清空剪切板()

> 清除剪切板内容。
> 
> 这是 $sys.clearClip 的中文叫法。

- 返回 : {布尔值} true 表示成功
- 版本 : 1.7.0


```javascript
$sys.清空剪切板();
```


### 获取剪切板()

> 获得剪切板文字：读取当前复制的内容。
> 
> 这是 $sys.getClip 的中文叫法。

- 返回 : {字符串} 剪切板文字
- 版本 : 1.7.0


```javascript
var 内容 = $sys.获取剪切板();
toast("剪切板：" + 内容);
```


### 设置剪切板(文本)

> 设置剪切板：把文字写进剪切板。
> 
> 这是 $sys.setClip 的中文叫法。

- 参数 : 文本 {字符串} 要复制的文字
- 返回 : {布尔值} true 表示成功
- 版本 : 1.7.0


```javascript
// 复制一段文字
$sys.设置剪切板("Hello AIGame !");
```


### 忽略电池优化(包名)

> 是否忽略电池优化：检查应用是否在白名单。
> 
> 这是 $sys.ignorePower 的中文叫法，仅部分低版本安卓可用。

- 参数 : 包名 {字符串} 应用包名
- 返回 : {布尔值} true 表示已忽略
- 版本 : 1.7.0


```javascript
var 是否忽略 = $sys.忽略电池优化("org.aigame.app");
toast("是否忽略电池优化：" + 是否忽略);
```


### 请求电池优化(包名)

> 请求忽略电池优化：弹框请用户授权。
> 
> 这是 $sys.requestIgnorePower 的中文叫法。

- 参数 : 包名 {字符串} 应用包名
- 版本 : 1.7.0


```javascript
$sys.请求电池优化("org.aigame.app");
```


### 保活(是否开启)

> 保活：开关前台保活服务。
> 
> 这是 $sys.stayAlive 的中文叫法。

- 参数 : 是否开启 {布尔值} true 开，false 关
- 版本 : 1.7.0


```javascript
$sys.保活(true);
$sys.保活(false);
```


### 有保活()

> 是否开启前台保活服务。
> 
> 这是 $sys.hasStayAlive 的中文叫法。

- 返回 : {布尔值} true 表示保活运行中
- 版本 : 1.7.0


```javascript
var 是否有保活 = $sys.有保活();
toast("保活状态：" + 是否有保活);
```


### 有指针()

> 判断是否开启指针：检查开发者指针位置显示。
> 
> 这是 $sys.hasPointer 的中文叫法。

- 返回 : {布尔值} true 表示已开启
- 版本 : 1.7.0


```javascript
if ($sys.有指针()) {
    toast("指针已开启");
}
```


### 指针(是否开启)

> 开发者指针授权：开关指针位置显示。
> 
> 这是 $sys.pointer 的中文叫法；开完等 1 秒再确认生效。

- 参数 : 是否开启 {布尔值} true 开，false 关
- 版本 : 1.7.0


```javascript
$sys.指针(true);
sleep(1000);
if ($sys.有指针()) {
    toast("指针已开启");
}
```


### 音量控制(是否开启)

> 设置音量控制：开关 App 内部音量接管。
> 
> 这是 $sys.volumeCtrl 的中文叫法。

- 参数 : 是否开启 {布尔值} true 开，false 关
- 版本 : 1.9.4


```javascript
// 开启音量控制
$sys.音量控制(true);
```
