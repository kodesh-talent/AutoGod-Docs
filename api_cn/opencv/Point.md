# Point - 点对象

- 更新时间:2026-10-22 10:56:19

> 坐标对象 Point，用两个整数保存一个位置。
> 
> x 是横坐标，y 是纵坐标；屏幕或图片通常以左上角 (0, 0) 为原点，向右和向下增加。
> Point 是脚本内置类名，可直接通过带参数构造方法创建；没有无参数构造。
> 对象只保存数字，不会检查坐标是否在屏幕内，也不会执行点击。找图等接口返回的点应先检查非空，并确认所在坐标系。



```javascript
var point = new Point(100, 200); // 横坐标在前，纵坐标在后。
log("横坐标：" + point.getX());
log("纵坐标：" + point.getY());
point.setX(120); // 修改数据不会操作设备。
log(point.x + "," + point.y);
```




### const {int} x;

> 保存横坐标。
> 
> 类型为 int（整数）。屏幕或图片坐标通常以左上角为原点，横向向右、纵向向下增加，单位像素。
> 坐标参照系取决于产生这个点的接口；局部图片坐标不一定是设备屏幕坐标，使用前确认是否需要加区域偏移。
> 这是公开字段，默认值为零，可以直接修改；零和负数不会被自动当成失败标记。


```javascript
var point = new Point(100, 200); // 创建一份教学坐标。
log(point.x); // 直接读取公开字段。
```

### getX()

> 读取横坐标。
> 
> 类型为 int（整数）。屏幕或图片坐标通常以左上角为原点，横向向右、纵向向下增加，单位像素。
> 坐标参照系取决于产生这个点的接口；局部图片坐标不一定是设备屏幕坐标，使用前确认是否需要加区域偏移。
> 输入参数：无；返回类型为 int，直接读取当前字段，不重新查找目标。

- 返回 : {int} 当前保存的横坐标


```javascript
var point = new Point(100, 200); // 创建一份教学坐标。
log(point.getX()); // 读取保存值。
```


### setX(x)

> 设置横坐标。
> 
> 类型为 int（整数）。屏幕或图片坐标通常以左上角为原点，横向向右、纵向向下增加，单位像素。
> 坐标参照系取决于产生这个点的接口；局部图片坐标不一定是设备屏幕坐标，使用前确认是否需要加区域偏移。
> 输入 x 类型为 int；输出类型为 void，没有返回值。只修改此坐标，不改变另一坐标，也不会移动或点击设备。

- 参数 : x {int} 新的横坐标，本方法不检查屏幕边界


```javascript
var point = new Point(100, 200); // 创建一份教学坐标。
point.setX(250); // 仅改变这个对象保存的数据。
log(point.getX());
```
