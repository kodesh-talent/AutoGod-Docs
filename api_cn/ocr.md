# $ocr - 文字识别

- 更新时间:2026-10-22 10:55:50

> 文字识别对象，脚本里叫 $ocr（中文文档里叫 $文字识别）。
> 
> 负责对截屏或本地图片做 OCR，把图里的文字读出来，还能拿到每段文字在屏幕上的坐标，常配合 $act 做自动点按。



```javascript
$ocr.init();
var text = $ocr.onlyRec("/sdcard/Pictures/text.png");
```




### 版本(版本名称)

> 选择要使用的 OCR 识别引擎（中文文档版）。
> 
> 可选值同英文 v 方法：mlkit / ppv5 / ncnn。
> 必须在识别之前调用。

- 参数 : 版本名称 {字符串} 引擎名称：mlkit / ppv5 / ncnn
- 版本 : 1.6.0


```javascript
//此函数要放在识别之前调用
$文字识别.版本("mlkit");
```


### 初始化()

> 初始化当前选择的 OCR 引擎（中文文档版）。
> 
> 加载识别模型，成功后才能做识别。
> 
> 在脚本开头调用一次即可。

- 返回 : {结果集} 识别结果集，用 是否成功() 判断成败，数据列表里有每段文字和坐标
- 版本 : 1.6.0


```javascript
$文字识别.初始化();
```


### 识别位置(文字, 配置)

> 识别文字拿位置
> 
> 识别后将把每行结果去除空格和换行符后,判断是否包含指定文字,如果包含则返回该文字识别出来的位置
> 
> 该函数其实是对'识别()'函数的封装,只是在识别到文字后,会判断文字关系是否包含指定文字,如果包含则返回该文字识别出来的位置

- 参数 : 文字 {字符串} 要在识别结果里查找的文字
- 参数 : 配置 {对象} 识别配置对象（范围/灰度化/颜色/阈值等，见示例）
- 返回 : {Point} 命中文字的坐标；没找到返回 null
- 版本 : 1.6.0


```javascript
//配置方式1:灰度化识别
var 配置1 = {
    范围: [0,0,200,100], //(可选)识别范围(为空则识别整个屏幕)
    是否灰度化: 是, //(必须)开启灰度化(默认:否),开启后会将图片转换为灰度图,识别速度会快很多,但是识别准确率会低一些
    是否保存图片: 是, //(可选)是否保存图片(默认:否),开启后会将识别到的图片保存到指定路径
    保存路径: "/sdcard/a.png" //(可选)配合是否保存图片，图片保存到的路径
};
//配置方式2:二值化识别
var 配置2 = {
    范围: [0,0,200,100], //(可选)识别范围(为空则识别整个屏幕)
    颜色: "#FFFFFF", //(必须)要识别的文字颜色
    阈值: 20, //(可选)二值化阈值(默认:20)推荐在20-50之间
    是否保存图片: 是, //(可选)是否保存图片(默认:否),开启后会将识别到的图片保存到指定路径
    保存路径: "/sdcard/a.png" //(可选)配合是否保存图片，图片保存到的路径
};
//上面的配置自己根据自身需求选择一个即可
//在屏幕上找"文字"两个字
var 识别结果 = $文字识别.识别位置("文字", 配置2);
if (识别结果 != 空) {
    //找到了就点它
    $动作.点击(识别结果);
}
```


### 识别单行(配置)

> 识别当前屏幕指定区域，将文字拼接成一行。
> 
> 输入类型为 Object，使用普通脚本对象填写 OcrOptions 的配置键。先取得截屏权限，再确保识别区域在截图范围内。
> 范围四个数依次为左上角横坐标、纵坐标、宽、高，单位像素；下例只是示范，需要按实际画面修改。
> 灰度模式把图片转成灰度后识别；二值化模式按文字颜色和阈值筛选像素。不同画面应选择合适方式，不保证哪种总是更快或更准。
> 不要在同一配置中混用同一选项的中英文键；字段优先级详见 OcrOptions。
> 返回类型为 String。按识别结果顺序去掉各条文字中的空白后直接拼接，不会在条目间补空格或换行，也不是只识别画面的第一行。
> 开启提取数字后会从拼接的文字中提取数字并用逗号分隔，结果仍是字符串。配置无法转换、识别失败时可能返回 null，未拼接出内容时可能是空字符串。
> 配置转换、图像处理或识别过程可能抛出异常，示例使用异常处理记录原因。
> 这里描述的是脚本内置入口：导出层 ApiOcr 将中文调用转到英文实现。不要把本类的中文占位方法当成可直接调用的 Java 实现。
> 结果对象和 Java 列表的读取方法使用实际提供的英文名称，不自行翻译方法名。

- 参数 : 配置 {Object} 可转换成 OcrOptions 的配置对象
- 返回 : {String} 拼接后的文字，可能为 null 或空字符串
- 版本 : 1.0.0


```javascript
// 提前取得截屏权限；把范围改为实际文字所在区域。
var 配置 = {
    范围: [0, 0, 300, 100],
    是否灰度化: true, // 本例选择灰度处理。
    是否保存图片: false // 示例不向设备保存图片。
};
配置.是否提取数字 = false; // 改成 true 可提取数字。
try {
    var 结果 = $文字识别.识别单行(配置);
    if (结果 != null && String(结果).length > 0) {
        日志(结果); // 使用拼接后的字符串。
    } else {
        日志("没有取得文字，请检查画面、权限和配置。");
    }
} catch (错误) {
    日志("文字识别异常：" + 错误);
}
```

### 识别(配置)

> 识别当前屏幕指定区域，返回包含文字和位置的结果对象。
> 
> 输入类型为 Object，使用普通脚本对象填写 OcrOptions 的配置键。先取得截屏权限，再确保识别区域在截图范围内。
> 范围四个数依次为左上角横坐标、纵坐标、宽、高，单位像素；下例只是示范，需要按实际画面修改。
> 灰度模式把图片转成灰度后识别；二值化模式按文字颜色和阈值筛选像素。不同画面应选择合适方式，不保证哪种总是更快或更准。
> 不要在同一配置中混用同一选项的中英文键；字段优先级详见 OcrOptions。
> 返回类型为 DetectResult。先检查对象非空，再调用 isSuccess() 判断成功与否；getData() 返回 List<DetectResultItem>，是 Java 列表。
> 每个 DetectResultItem 可以用 getWord() 读取文字，用坐标读取方法获取位置；列表用 size() 和 get() 遍历。
> 配置无法转换时可能返回 null；获取截图失败等情况也可能返回表示失败的结果对象，不能只检查非空就当作成功。
> 配置转换、图像处理或识别过程可能抛出异常，示例使用异常处理记录原因。
> 这里描述的是脚本内置入口：导出层 ApiOcr 将中文调用转到英文实现。不要把本类的中文占位方法当成可直接调用的 Java 实现。
> 结果对象和 Java 列表的读取方法使用实际提供的英文名称，不自行翻译方法名。

- 参数 : 配置 {Object} 可转换成 OcrOptions 的配置对象
- 返回 : {DetectResult} 识别结果对象；可能为 null，也可能表示失败
- 版本 : 1.0.0


```javascript
// 提前取得截屏权限；把范围改为实际文字所在区域。
var 配置 = {
    范围: [0, 0, 300, 100],
    是否灰度化: true, // 本例选择灰度处理。
    是否保存图片: false // 示例不向设备保存图片。
};
try {
    var 结果 = $文字识别.识别(配置);
    if (结果 != null && 结果.isSuccess()) {
        var 条目列表 = 结果.getData(); // 取得文字条目列表。
        if (条目列表 != null) {
            for (var 序号 = 0; 序号 < 条目列表.size(); 序号++) {
                var 条目 = 条目列表.get(序号);
                日志(条目.getWord()); // 读取一个条目的文字。
                日志("中心位置：" + 条目.getCx() + "," + 条目.getCy());
            }
        }
    } else {
        日志("识别未成功，请检查截屏权限、区域和引擎。");
    }
} catch (错误) {
    日志("文字识别异常：" + 错误);
}
```
