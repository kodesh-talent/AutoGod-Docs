# OcrOptions - 识别配置

- 更新时间:2026-10-22 10:55:50

> 屏幕文字识别的配置数据。
> 
> 把普通脚本对象传给 $ocr 的配置重载，或 $文字识别 的对应中文方法，内部会转换成此配置。
> 此类只有带参数的构造方法，没有无参数构造；初学者请采用下面的普通对象写法，不要写无参数的新建调用。
> 私有字段不应直接从脚本读写。颜色和阈值优先取中文字段；范围、灰度、提取数字、保存开关及保存路径优先取英文字段，只有优先字段为 null 才读取另一份。
> 字段声明中的初值不应等同于所有反序列化方式下的有效值，请在脚本中显式填写关键选项。
> 识别单行返回 String 字符串；识别结果集方法返回 DetectResult，包含文字条目和位置。识别需要截图权限和可用的识别引擎。



```javascript
// 先取得截屏权限，让需要识别的文字出现在屏幕上。
// 这里创建普通脚本对象，不直接访问配置类中的私有字段。
var options = {
    gray: true,
    region: [0, 0, 300, 100]
};
try {
    var text = $ocr.line(options); // 配置会转换为识别选项。
    if (text != null && String(text).length > 0) {
        log(text); // 返回的是文字字符串。
    } else {
        log("没有识别到文字，请检查权限、画面和配置。");
    }
} catch (error) {
    log("文字识别失败：" + error);
}
```

### const {String} 颜色;

> 二值化时要保留的文字颜色的中文配置项。
> 
> 字段类型为 String，这是 Java 内部私有字段；脚本请通过普通配置对象中同名的键传值，不要直接给 OcrOptions 的私有字段赋值。
> 颜色字符串，例如 #EEEEEE 表示浅灰白色。二值化按这个颜色及阈值筛选像素；灰度模式不使用这个颜色。无效颜色格式会在二值化处理中改用 #EEEEEE。
> 读取时优先使用 颜色，仅当它为 null 时才读取另一种语言的字段；false、零和空字符串都不等于 null。
> 不要在一份配置里混用两种语言的同类选项，否则可能读到优先字段而忽略本次设置。


```javascript
// 先取得截屏权限，让需要识别的文字出现在屏幕上。
// 这里创建普通脚本对象，不直接访问配置类中的私有字段。
var 配置 = {
    颜色: "#EEEEEE",
    是否灰度化: false
};
try {
    var 文字 = $文字识别.识别单行(配置); // 配置会转换为识别选项。
    if (文字 != null && String(文字).length > 0) {
        日志(文字); // 返回的是文字字符串。
    } else {
        日志("没有识别到文字，请检查权限、画面和配置。");
    }
} catch (错误) {
    日志("文字识别失败：" + 错误);
}
```
