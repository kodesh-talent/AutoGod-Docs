# FcConfig - 文件选择配置

- 更新时间:2026-10-22 10:55:48

> 文件选择器配置对象。
> 
> 先新建对象，再填写需要改变的选项，最后传给 $fc.show 或 $文件选择器.显示。
> 中英文配置是独立字段：中文值不为 null 时优先，否则使用英文字段。建议同一份配置统一采用一种语言。



```javascript
// 新建配置，每次示例都使用独立对象。
var options = new FcConfig();
// 需要悬浮窗和存储访问权限，选好后点确定才触发回调。
$fc.show(function (paths) {
    // 回调收到 Java 列表，用 size() 和 get() 遍历。
    if (paths != null) {
        for (var index = 0; index < paths.size(); index++) {
            log(paths.get(index)); // 每一项都是路径字符串。
        }
    }
}, options);
// 显示方法没有返回路径；后续文件处理应写在回调中。
```

### const {String} 模式;

> 选择模式的中文配置字段。
> 
> 类型为 String（字符串）。
> 此字段初始为 null，表示未设置中文覆盖值；此时使用 mode 的值，后者默认是 "single"。
> 中文字段 模式 不为 null 时优先使用中文值，否则使用 mode；给其中一个字段赋值不会同步另一个。
> 填写 single 表示单选，multiple 表示多选；中文可以填写“单选”或“多选”。实际实现按开头判断，以小写 m 或“多”开头才启用多选，其余按单选处理。
> 修改配置只影响随后打开的选择器，不会改变已经显示的选择器。


```javascript
// 新建配置，每次示例都使用独立对象。
var 配置 = new FcConfig();
配置.模式 = "多选"; // 设置本次要演示的选项。
// 需要悬浮窗和存储访问权限，选好后点确定才触发回调。
$文件选择器.显示(function (路径列表) {
    // 回调收到 Java 列表，用 size() 和 get() 遍历。
    if (路径列表 != null) {
        for (var 序号 = 0; 序号 < 路径列表.size(); 序号++) {
            日志(路径列表.get(序号)); // 每一项都是路径字符串。
        }
    }
}, 配置);
// 显示方法没有返回路径；后续文件处理应写在回调中。
```


### const {String} 类型;

> 选择类型的中文配置字段。
> 
> 类型为 String（字符串）。
> 此字段初始为 null，表示未设置中文覆盖值；此时使用 type 的值，后者默认是 "file"。
> 中文字段 类型 不为 null 时优先使用中文值，否则使用 type；给其中一个字段赋值不会同步另一个。
> 填写 file 选择文件、dir 选择目录、all 两者都可选；中文可填写“文件”“目录”“所有”。这些设置控制勾选类型，不会阻止浏览目录。
> 修改配置只影响随后打开的选择器，不会改变已经显示的选择器。

### const {String} 默认路径;

> 打开时显示的目录的中文配置字段。
> 
> 类型为 String（字符串）。
> 此字段初始为 null，表示未设置中文覆盖值；此时使用 path 的值，后者默认是 外部存储根目录。
> 中文字段 默认路径 不为 null 时优先使用中文值，否则使用 path；给其中一个字段赋值不会同步另一个。
> 请填写存在且允许访问的目录路径。路径为空或不存在时，当前实现改用外部存储根目录；不会为你新建目录。
> 修改配置只影响随后打开的选择器，不会改变已经显示的选择器。


```javascript
// 新建配置，每次示例都使用独立对象。
var 配置 = new FcConfig();
配置.默认路径 = "/sdcard/Download"; // 设置本次要演示的选项。

$文件选择器.显示(function (路径列表) {
    // 回调收到 Java 列表，用 size() 和 get() 遍历。

            日志(路径列表.get(序号)); // 每一项都是路径字符串。
        }
    }
}, 配置);
// 显示方法没有返回路径；后续文件处理应写在回调中。
```


### const {String} 根路径;

> 返回上级目录时的停止位置的中文配置字段。
> 
> 类型为 String（字符串）。
> 此字段初始为 null，表示未设置中文覆盖值；此时使用 root 的值，后者默认是 外部存储根目录。
> 中文字段 根路径 不为 null 时优先使用中文值，否则使用 root；给其中一个字段赋值不会同步另一个。
> 请同时把打开路径设置到根路径内部。当前返回逻辑在路径等于根路径时停止，不是安全隔离机制，也不会授予存储权限。
> 修改配置只影响随后打开的选择器，不会改变已经显示的选择器。


```javascript
// 新建配置，每次示例都使用独立对象。
var 配置 = new FcConfig();
配置.根路径 = "/sdcard/Download"; // 设置本次要演示的选项。
配置.默认路径 = "/sdcard/Download"; // 从同一个根目录开始浏览。
// 需要悬浮窗和存储访问权限，选好后点确定才触发回调。
$文件选择器.显示(function (路径列表) {
    // 回调收到 Java 列表，用 size() 和 get() 遍历。
    if (路径列表 != null) {
        for (var 序号 = 0; 序号 < 路径列表.size(); 序号++) {
            日志(路径列表.get(序号)); // 每一项都是路径字符串。
        }
    }
}, 配置);
// 显示方法没有返回路径；后续文件处理应写在回调中。
```


### const {String} 后缀;

> 可勾选文件的后缀筛选的中文配置字段。
> 
> 类型为 String（字符串）。
> 此字段初始为 null，表示未设置中文覆盖值；此时使用 ext 的值，后者默认是 空字符串。
> 中文字段 后缀 不为 null 时优先使用中文值，否则使用 ext；给其中一个字段赋值不会同步另一个。
> 可填写 jpg,png，空字符串表示不额外筛选。当前实现忽略大小写，以筛选字符串是否包含文件后缀来决定勾选框；并不是严格拆分后的后缀集合匹配，也不会隐藏整行文件。筛选可能覆盖文件类型对勾选框的限制，选择目录时建议留空。
> 修改配置只影响随后打开的选择器，不会改变已经显示的选择器。


```javascript
// 新建配置，每次示例都使用独立对象。
var 配置 = new FcConfig();
配置.后缀 = "jpg,png"; // 设置本次要演示的选项。
// 需要悬浮窗和存储访问权限，选好后点确定才触发回调。
$文件选择器.显示(function (路径列表) {
    // 回调收到 Java 列表，用 size() 和 get() 遍历。

// 显示方法没有返回路径；后续文件处理应写在回调中。
```
