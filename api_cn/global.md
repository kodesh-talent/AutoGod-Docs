# $global - 全局函数

- 更新时间:2026-10-22 10:55:47

> 全局函数（脚本里直接写名字就能用，不需要加 $ 前缀）。
> 
> 这里放的是最常用的一批小工具：等待几秒、弹提示框、显示图片、操作剪贴板、
> 读取当前前台应用的包名/界面名、取当前时间等。
> 
> 这些函数大多同时提供英文版和中文版，功能完全一样，按习惯选一个用即可。



```javascript
sleep(1000);                 //等待 1 秒
tip("脚本开始运行");          //弹一个小提示
var pkg = curPkg();          //读当前前台应用包名
log("当前包名：" + pkg);
```




### 睡觉(时长)

> 让脚本暂停一会儿（中文方法名“睡觉”），和 sleep 一样，单位毫秒。

- 参数 : 时长 {int} 要等待的毫秒数
- 版本 : 1.0.0


```javascript
睡觉(1000);   //等待 1 秒钟
```


### 等待(时长)

> 让脚本暂停一会儿（中文方法名“等待”），和 sleep 一样，单位毫秒。

- 参数 : 时长 {int} 要等待的毫秒数
- 版本 : 1.6.8


```javascript
等待(1000);   //等待 1 秒钟
```


### 提示(信息)

> 弹出一个小提示框，显示一段文字（中文方法名“提示”），和 tip 一样。

- 参数 : 信息 {String} 要显示的提示文字
- 版本 : 1.6.8


```javascript
提示("我是提示内容");
```


### 弹窗(标题, 信息)

> 弹出一个对话框（中文方法名“弹窗”），和 alert 一样，可指定标题和内容。

- 参数 : 标题 {String} 对话框标题
- 参数 : 信息 {String} 对话框内容
- 版本 : 1.6.8


```javascript
弹窗("提示对话框", "我很好");
```


### 显示图片(图片或路径)

> 在屏幕上悬浮显示一张图片（中文方法名“显示图片”），和 showImg 一样。
> 
> 参数可以传图片路径，也可以传 $img 读出来的图片对象。

- 参数 : 图片或路径 {Image|String} 图片对象或图片路径
- 版本 : 1.6.8


```javascript
//方式一：直接传图片路径
显示图片("/sdcard/Pictures/t01.png");
//方式二：先读成图片对象再显示
var img = $img.read("/sdcard/Pictures/t01.png");
显示图片(img);
```


### 关闭绘制日志()

> 关闭屏幕上的绘制日志悬浮窗（中文方法名“关闭绘制日志”），和 closeLog 一样。

- 版本 : 1.6.8


```javascript
关闭绘制日志();
```


### 关闭绘制()

> 关闭所有绘制悬浮窗（中文方法名“关闭绘制”），和 closeDraw 一样。

- 版本 : 1.6.9


```javascript
关闭绘制();
```


### 清空绘制()

> 清空当前画出来的内容，但不关闭绘制悬浮窗（中文方法名“清空绘制”），和 clearDraw 一样。

- 版本 : 1.6.8


```javascript
清空绘制();
```


### 获取剪切板()

> 读取手机剪贴板里当前复制的文字（中文方法名“获取剪切板”），和 getClip 一样。

- 返回 : {String} 剪贴板里的文字
- 版本 : 1.6.8


```javascript
var 内容 = 获取剪切板();
log("剪贴板内容：" + 内容);
```


### 设置剪切板(文本)

> 把一段文字写进手机剪贴板（中文方法名“设置剪切板”），和 setClip 一样。

- 参数 : 文本 {String} 要复制到剪贴板的文字
- 版本 : 1.6.8


```javascript
设置剪切板("我是剪贴板内容");
```


### 剪切板有内容()

> 判断剪贴板里现在有没有内容（中文方法名“剪切板有内容”），和 hasClip 一样。

- 返回 : {boolean} 有内容返回 true，没有返回 false
- 版本 : 1.6.8


```javascript
if (剪切板有内容()) {
    var 内容 = 获取剪切板();
    log("剪贴板内容：" + 内容);
}
```


### 清空剪切板()

> 清空剪贴板里的内容（中文方法名“清空剪切板”），和 clearClip 一样。

- 返回 : {boolean} 清空成功返回 true
- 版本 : 1.6.8


```javascript
清空剪切板();
```


### 当前包名()

> 读取当前前台应用的包名（中文方法名“当前包名”），和 curPkg 一样。

- 返回 : {String} 当前前台应用的包名
- 版本 : 1.6.8


```javascript
var 包名 = 当前包名();
log("当前前台应用包名：" + 包名);
```


### 当前类名()

> 读取当前前台界面的活动名（中文方法名“当前类名”），和 curCls 一样。

- 返回 : {String} 当前界面的活动名
- 版本 : 1.6.8


```javascript
var 类名 = 当前类名();
log("当前界面活动名：" + 类名);
```


### 当前时间()

> 读取当前的时间戳（中文方法名“当前时间”），和 curTime 一样，单位毫秒。

- 返回 : {long} 当前时间戳，单位毫秒
- 版本 : 1.7.8


```javascript
var 时间戳 = 当前时间();
log("当前时间戳：" + 时间戳);
```


### 信息(内容)

> 悬浮提示：弹出一条土司信息。
> 
> 这是 info 的中文叫法。

- 参数 : 内容 {字符串...} 要显示的内容


```javascript
信息("提示信息");
```


### 信息日志(信息)

> 悬浮土司加控制台打印：既弹提示又写日志。
> 
> 这是 infoLog 的中文叫法。

- 参数 : 信息 {字符串...} 要显示和打印的内容


```javascript
信息日志("提示信息");
```


### 土司(信息)

> 系统土司：弹一条短提示。
> 
> 这是 toast 的中文叫法；部分手机需开启通知权限才能悬浮显示。

- 参数 : 信息 {字符串...} 要显示的内容


```javascript
土司("提示信息");
```


### 土司日志(信息)

> 系统土司加控制台打印。
> 
> 这是 toastLog 的中文叫法。

- 参数 : 信息 {字符串...} 要显示和打印的内容


```javascript
土司日志("提示信息");
```


### 日志(信息)

> 控制台日志：打印一条信息不弹窗。
> 
> 这是 log 的中文叫法。

- 参数 : 信息 {字符串...} 要打印的内容


```javascript
日志("信息");
```


### 打印(信息)

> 打印：控制台输出一条信息。
> 
> 这是 print 的中文叫法。

- 参数 : 信息 {字符串...} 要打印的内容


```javascript
打印("信息");
```


### 随机数()

> 随机数：生成 0 到 1 之间的小数。
> 
> 这是 random() 的中文叫法。

- 返回 : {float} 0 到 1 之间的随机小数


```javascript
log(随机数());
```


### 随机数(最大值)

> 随机数：生成 0 到最大值之间的整数。
> 
> 这是 random(max) 的中文叫法。

- 参数 : 最大值 {整数} 上限
- 返回 : {int} 0 到最大值之间的随机整数


```javascript
log(随机数(10));
```


### 随机数(最小值, 最大值)

> 随机数：生成最小值到最大值之间的整数。
> 
> 这是 random(min,max) 的中文叫法。

- 参数 : 最小值 {整数} 下限
- 参数 : 最大值 {整数} 上限
- 返回 : {int} 最小值到最大值之间的随机整数


```javascript
log(随机数(10, 30));
```


### 导入(路径)

> 导入模块：加载外部 JS 文件并拿到导出对象。
> 
> 这是 require 的中文叫法。

- 参数 : 路径 {字符串} 模块脚本路径
- 返回 : {JsObject} 模块导出的对象或类


```javascript
var MyClass = 导入("mCls.js");
var obj = new MyClass();
```
