# $szk - Shizuku工具

- 更新时间:2026-10-22 10:55:51

> Shizuku 工具对象（脚本里写作 $szk，中文名叫 $始祖库）。
> 
> Shizuku 是一个能让 App 以"系统级权限"执行操作的工具。装好并开启 Shizuku 后，$szk 就能帮你
> 做一些普通权限做不到的事：模拟点击/滑动、长按、返回/主页键、输入文字、强停应用、改分辨率、
> 直接执行 shell 命令等。
> 
> 新手提示：用之前要先确认 Shizuku 已经授权。脚本里先调用 hasPermit 检查，没权限就调用
> getPermit 去申请。很多手势 $act 已经封装好了，Shizuku 可用时底层会自动走这里。



```javascript
// 先检查 Shizuku 权限有没有拿到
var allowed = $szk.hasPermit();
if (allowed) {
    log("Shizuku 已授权，可以使用 $szk");
} else {
    log("还没授权，先调用 $szk.getPermit()");
}
```




### 获取权限()

> 获取权限：申请 Shizuku 授权并阻塞等待。
> 
> 这是 $szk.getPermit 的中文叫法。

- 版本 : 1.7.0


```javascript
// 申请 Shizuku 权限
$szk.获取权限();
```


### 有权限()

> 是否可用：检查有没有 Shizuku 权限。
> 
> 如果还没有服务实例，会尝试自动重连，连上了也算有权限。这是 $szk.hasPermit 的中文叫法。

- 返回 : {布尔值} 已授权返回 true，否则返回 false
- 版本 : 1.7.0


```javascript
// 检查是否已授权
if ($szk.有权限()) {
    log("已授权");
}
```


### 启用指针(是否启用)

> 启用指针：打开或关闭开发者选项的指针位置显示。
> 
> 这是 $szk.enablePointer 的中文叫法。

- 参数 : 是否启用 {布尔值} true 打开，false 关闭
- 版本 : 1.7.0


```javascript
// 打开指针位置显示
$szk.启用指针(true);
```


### 等待权限()

> 等待权限：阻塞等待 Shizuku 授权完成。
> 
> 这是个阻塞方法，执行完才会继续后面的代码。这是 $szk.waitPermit 的中文叫法。

- 返回 : {布尔值} 拿到权限返回 true，否则返回 false
- 版本 : 1.7.0


```javascript
// 阻塞等待权限
var result = $szk.等待权限();
log("结果：" + result);
```


### 等待权限(等待回调)

> 等待权限（异步）：授权结果通过回调返回。
> 
> 这是带回调版 $szk.waitPermit 的中文叫法。

- 参数 : 等待回调 {function(成功布尔)} 权限就绪后的回调
- 版本 : 1.7.0


```javascript
// 异步等待并回调
$szk.等待权限(function() {
    log("权限就绪");
});
```


### 点击(x, y)

> 点击：在 (x, y) 位置模拟一次轻点。
>

### 执行(命令)

### 执行(命令, 信息回调, 异常回调)

> 执行命令（带回调）：输出和错误分别回调。
> 
> 这是带回调版 $szk.exe 的中文叫法。

- 参数 : 命令 {字符串} shell 命令
- 参数 : 信息回调 {function(info){}} 普通输出回调
- 参数 : 异常回调 {function(err){}} 错误输出回调
- 版本 : 1.7.0


```javascript

    function(信息) { log(信息); },
    function(异常) { log(异常); }
);
```

### 执行(命令, 开始回调, 信息回调, 异常回调, 结束回调)

> 执行命令（全过程回调）：开始、输出、错误、结束都能收到。
> 
> 这是最完整版 $szk.exe 的中文叫法。

- 参数 : 命令 {字符串} shell 命令
- 参数 : 开始回调 {function(){}} 开始执行回调
- 参数 : 信息回调 {function(info){}} 普通输出回调
- 参数 : 异常回调 {function(err){}} 错误输出回调

- 版本 : 1.7.0
