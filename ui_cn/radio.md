### 存储关键字 - 应用内存储

> 应用内存储
> 
> 通过storeKey(存储关键字)指定一个存储布尔值的关键字，获取值时可以直接通过$storage($存储)获取布尔值。
> 
> 注意：不同的控件存储的类型不同，对于本控件(开关)则存储的是布尔值类型，表达当前是否被选中


```html
// 用字符串保存布局；标签表示控件，属性控制控件的外观或初始状态。
var 布局内容 =
    "<!-- 你必须在ui(界面)节点中通过store(存储)指定$storage($存储)的命名空间，等价于使用代码：var storage = $storage.create(\"MyAppRadio\"); -->\n" +
    "<界面 存储=\"MyAppRadio\">\n" +
    "    <状态栏 />\n" +
    "    <!-- 使用storeKey(存储关键字)属性，指定关键字，等价于使用代码：var data = $storage.create(\"MyAppRadio\").getBool(\"吃饭\"); -->\n" +
    "    <!-- 使用storeDef(存储默认值)属性，指定默认值，等价于使用代码：var data = $storage.create(\"MyAppRadio\").getBool(\"吃饭\",true); -->\n" +
    "    <单选按钮 存储默认值=\"是\" 存储关键字=\"吃饭\" 文本=\"吃饭\" />\n" +
    "    <单选按钮 存储默认值=\"否\" 存储关键字=\"睡觉\" 文本=\"睡觉\" />\n" +
    "</界面>";
// 解析布局得到界面对象，再显示界面。
var 界面 = $界面.解析布局(布局内容);
界面.显示();
```


如果我们已经配置好了应用内存储，则可以直接获取数据：

注意：一、要使用应用内存储，必须在ui(界面)节点指定属性store(存储)的值，该值指定存储的命名空间；
二、不是所有的控件都支持应用内存储；
三、不同的控件存储的数据类型可能都不一致，例如：输入类型的控件存储的是字符串类型，开关、多选框存储的就是布尔类型的数据。


```javascript
//创建(或者加载)存储对象
var storage = $storage.create("MyAppRadio");//名称要一致
//获取数据
var data = storage.getBoolean("eat",false);//数据类型是布尔值
```


## 二、常用函数


### 是选中的()

> “是选中的”是 isChecked 的中文名字：看看单选按钮现在有没有被选中。

- 返回 : {Boolean} 选中了返回 true，没选中返回 false
- 版本 : 1.8.2


```javascript
var ui = $ui.layout('<ui><statusbar/><radio id="mRadio" text="吃饭"/></ui>');
ui.show(); //把界面显示出来
var radio = ui.id("mRadio"); //根据 id 拿到这个单选按钮
if (radio.是选中的()) {
    log("选中了");
}
```


### 设置选中(状态)

> “设置选中”是 check 的中文名字：代码里主动选中或取消这个单选按钮。

- 参数 : 状态 {Boolean} true 选中，false 取消


```javascript
var ui = $ui.layout('<ui><statusbar/><radio id="mRadio" text="吃饭"/></ui>');
ui.show(); //把界面显示出来
var radio = ui.id("mRadio"); //根据 id 拿到这个单选按钮
radio.设置选中(true); //选中它
```


### 监听选中(回调)

> “监听选中”是 onCheck 的中文名字：用户点单选按钮时回调，并告诉你现在选中还是取消。

- 参数 : 回调 {function} 选中变化回调，参数是 true（选中）或 false（取消）


```javascript
var ui = $ui.layout('<ui><statusbar/><radio id="mRadio" text="吃饭"/></ui>');
ui.show(); //把界面显示出来
var radio = ui.id("mRadio"); //根据 id 拿到这个单选按钮
radio.监听选中(function(isChecked) {
    if (isChecked) {
        log("被选中了");
    }
});
```


### 设置重力(重力)

> “设置重力”是 setGravity 的中文名字：改单选按钮内部内容的对齐方式。

- 参数 : 重力 {String} 对齐方式，例如 "中间"、"开始"、"中间|下"


```javascript
var ui = $ui.layout('<ui><statusbar/><radio id="mRadio" text="居中" w="max"/></ui>');
ui.show(); //把界面显示出来
var radio = ui.id("mRadio"); //根据 id 拿到这个单选按钮
radio.设置重力("中间"); //居中
```


### 设置文字(文本)

> “设置文字”是 setText 的中文名字：改单选按钮旁边显示的文字。

- 参数 : 文本 {String} 要显示的新文字


```javascript
var ui = $ui.layout('<ui><statusbar/><radio id="mRadio" text="旧文字"/></ui>');
ui.show(); //把界面显示出来
var radio = ui.id("mRadio"); //根据 id 拿到这个单选按钮

```


### 获取文字()

> “获取文字”是 getText 的中文名字：读出单选按钮旁边现在显示的文字。

- 返回 : {String} 当前显示的文字；没有文字时返回空字符串


```javascript
var ui = $ui.layout('<ui><statusbar/><radio id="mRadio" text="吃饭"/></ui>');
ui.show(); //把界面显示出来
var radio = ui.id("mRadio"); //根据 id 拿到这个单选按钮
var t = radio.获取文字(); //读出文字
log("文字是:" + t);
```
