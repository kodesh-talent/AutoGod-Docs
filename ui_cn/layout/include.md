# 包含布局

- 更新时间:2026-10-22 10:58:39

> 包含布局-include
> 
> 包含布局主要用于引入其他布局文件，避免单个布局文件过大导致代码臃肿。
> 包含布局的本质就是一个线性布局，所以在使用的时候遵循线性布局的规则即可。
> 是布局父类的(XLayout)的子类,因此可以使用XLayout的所有方法
> 
> 原生类型:{android.widget.LinearLayout}




## 一、常用属性


### 路径 - 子界面路径

> 子界面路径


```html
// 把布局写成字符串；引号内是控件名称和属性，修改属性值即可练习。
// 示例引用的图片或子布局文件需要先放到项目中，并按实际位置修改路径。
// 这里只演示容器属性；空容器可能不明显，可在容器内加入文本等子控件观察。
var 布局内容 = `
<界面>
    <状态条 />
    <包含布局 路径="界面/子界面.xml" />
</界面>
`;
// 解析字符串，得到管理这张界面的对象；接着显示界面。
var 界面 = $界面.解析布局(布局内容);
界面.显示();
```
