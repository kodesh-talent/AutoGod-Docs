# 小片组

- 更新时间:2026-10-22 10:58:40

> 小片组-chip-group
> 
> 是布局父类的(XLayout)的子类
> 
> 原生类型:{com.google.android.material.chip.ChipGroup}




## 一、常用属性

### 选中(文本)

> “选中”是 check(文字) 的中文名字：按文字内容选中小片组里的小片。

- 参数 : 文本 {String} 要选中的小片上显示的文字


```javascript
//先用一段 XML 创建界面：一个小片组里放两个可选中的小片
var ui = $ui.layout('<ui><statusbar/><chip-group id="g1"><chip text="选项1" checkable="true"/><chip text="选项2" checkable="true"/></chip-group></ui>');
ui.show(); //把界面显示出来
var g = ui.id("g1"); //根据 id 拿到这个小片组
g.选中("选项1"); //勾上文字是“选项1”的小片
```


### 反选(文本)

> 按文字选中匹配的小片，并取消其他小片的选中状态。
> 
> 虽然方法名叫“反选”，实际行为不是把所有小片的选中状态逐个取反。
> 输入 CharSequence 文本，脚本通常传字符串；使用完整文字匹配，不是只匹配其中一部分。
> 传 null 时会记录提示并直接结束。请先把小片设置为可选中，否则无法正常演示选中效果。
> 返回类型为 void，没有返回值。操作在界面线程中执行，最终状态也受小片组的选择规则限制。

- 参数 : 文本 {CharSequence} 需要匹配的小片完整文字；传 null 时不修改状态。


```javascript
// 创建两个可以选中的小片，并给小片组取一个查找用的名字。
var 界面 = $界面.解析布局("<界面><状态条 /><小片组 标识=\"选项组\"><小片 文本=\"选项1\" 可选中=\"是\" /><小片 文本=\"选项2\" 可选中=\"是\" /></小片组></界面>");
var 小片组 = 界面.找控件("选项组");
// 选中第二项，同时取消其他项的选中状态。
小片组.反选("选项2");
界面.显示();
```


### 选中(下标)

> “选中”是 check(下标) 的中文名字：按位置选中小片组里的第几个小片，下标从 0 开始。

- 参数 : 下标 {Number} 下标，从 0 开始


```javascript
//先用一段 XML 创建界面：一个小片组里放两个可选中的小片
var ui = $ui.layout('<ui><statusbar/><chip-group id="g1"><chip text="选项1" checkable="true"/><chip text="选项2" checkable="true"/></chip-group></ui>');
ui.show(); //把界面显示出来
var g = ui.id("g1"); //根据 id 拿到这个小片组
g.选中(1); //选中第 2 个小片（下标 1）
```


### 子项数量()

> “子项数量”是 childCount 的中文名字：数一下小片组里一共有几个小片。

- 返回 : {int} 小片组里小片的个数


```javascript
//先用一段 XML 创建界面：一个小片组里放两个小片
var ui = $ui.layout('<ui><statusbar/><chip-group id="g1"><chip text="A"/><chip text="B"/></chip-group></ui>');
ui.show(); //把界面显示出来
var g = ui.id("g1"); //根据 id 拿到这个小片组
var 数量 = g.子项数量(); //数一下
ui.toast("一共 " + 数量 + " 个");
```


### 获得子项(下标)

> “获得子项”是 getChild 的中文名字：按下标拿到某个小片的安卓原生 Chip 对象，下标从 0 开始。
> 
> 返回的是安卓原生对象，一般小白用不到；越界时返回 null。

- 参数 : 下标 {Number} 下标，从 0 开始
- 返回 : {Chip} 对应的安卓原生小片对象；越界时返回 null


```javascript
//先用一段 XML 创建界面：一个小片组里放两个小片
var ui = $ui.layout('<ui><statusbar/><chip-group id="g1"><chip text="A"/><chip text="B"/></chip-group></ui>');
ui.show(); //把界面显示出来
var g = ui.id("g1"); //根据 id 拿到这个小片组
var chip = g.获得子项(0); //拿到第 1 个小片的原生对象
if (chip != null) {
    ui.toast("文字是：" + chip.getText());
}
```
