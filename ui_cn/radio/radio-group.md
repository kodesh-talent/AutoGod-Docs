# 单选按钮组

- 更新时间:2026-10-22 10:58:42

> 单选按钮组-radio-group
> 
> 在此布局中，单选按钮会自动取消和选中，保证一组按钮只被选中一个
> 
> 是布局父类的(XLayout)的子类
> 
> 原生类型:{android.widget.RadioGroup}




## 一、常用属性


### 方向 - 排列方向

> 设置排列方向
> 
> 可选参数:v(纵向),h(横向)


```html

var 布局内容 = `
<界面>
    <状态条 />
    <单选按钮组 方向="横向">
        <单选按钮 文本="选项1"/>
        <单选按钮 文本="选项2"/>
    </单选按钮组>
</界面>
`;
// 解析布局得到界面对象，再显示界面。
var 界面 = $界面.解析布局(布局内容);
```

### 存储关键字 - 应用内存储

> 应用内存储
> 
> 通过storeKey(存储关键字)指定一个存储整数的关键字，获取值时可以直接通过$storage($存储)获取进度值。
> 
> 注意：不同的控件存储的类型不同，对于本控件(进度条)则存储的是整数类型，表达当前进度值


```html
// 用字符串保存布局；标签表示控件，属性控制控件的外观或初始状态。
var 布局内容 =
    "<!-- 你必须在ui(界面)节点中通过store(存储)指定$storage($存储)的命名空间，等价于使用代码：var storage = $storage.create(\"MyAppProgress\"); -->\n" +
    "<界面 存储=\"MyRadioGroup\">\n" +
    "    <状态栏 />\n" +
    "    <!-- 使用storeKey(存储关键字)属性，指定关键字，等价于使用代码：var data = $storage.create(\"MyRadioGroup\").getInt(\"下标\"); -->\n" +
    "    <!-- 使用storeDef(存储默认值)属性，指定关键字，等价于使用代码：var data = $storage.create(\"MyRadioGroup\").getInt(\"下标\",0); -->\n" +
    "    <单选按钮组 存储关键字=\"下标\" 存储默认值=\"0\">\n" +
    "        <单选按钮 文本=\"吃饭\"/>\n" +
    "        <单选按钮 文本=\"睡觉\"/>\n" +
    "        <单选按钮 文本=\"游戏\"/>\n" +
    "    </单选按钮组>\n" +
    "</界面>";
// 解析布局得到界面对象，再显示界面。
var 界面 = $界面.解析布局(布局内容);
界面.显示();
```


如果我们已经配置好了应用内存储，则可以直接获取数据：

注意：一、要使用应用内存储，必须在ui(界面)节点指定属性store(存储)的值，该值指定存储的命名空间；
二、不是所有的控件都支持应用内存储；
三、不同的控件存储的数据类型可能都不一致，例如：输入类型的控件存储的是字符串类型，开关、多选框存储的就是布尔类型的数据。


```javascript
//创建(或者加载)存储对象
var storage = $storage.create("MyRadioGroup");//名称要一致
//获取数据
var data = storage.getInt("index",0);//数据类型是整数
```


### 选中(下标)

> “选中”是 check 的中文名字：代码里主动选中组里第几个按钮。

- 参数 : 下标 {Number} 要选中的按钮下标，从 0 开始


```javascript
var ui = $ui.layout('<ui><statusbar/><radio-group id="mRg" w="max"><radio text="吃饭"/><radio text="睡觉"/><radio text="游戏"/></radio-group></ui>');
ui.show(); //把界面显示出来
var rg = ui.id("mRg"); //根据 id 拿到这个单选按钮组
rg.选中(1); //选中第二个
```


### 监听选中(回调函数)

> “监听选中”是 onCheck 的中文名字：用户点组里按钮时回调，并告诉你被选按钮的下标。

- 参数 : 回调函数 {function} 选中回调，参数是被选中按钮的下标（从 0 开始）


```javascript
var ui = $ui.layout('<ui><statusbar/><radio-group id="mRg" w="max"><radio text="吃饭"/><radio text="睡觉"/><radio text="游戏"/></radio-group></ui>');
ui.show(); //把界面显示出来
var rg = ui.id("mRg"); //根据 id 拿到这个单选按钮组
rg.监听选中(function(index) {
    log("你选了第" + (index + 1) + "个");
});
```


### 获取选中下标()

> “获取选中下标”是 getCheckedIndex 的中文名字：读出当前选中的是第几个按钮。

- 返回 : {Number} 选中按钮的下标（从 0 开始）；一个都没选返回 -1


```javascript
var ui = $ui.layout('<ui><statusbar/><radio-group id="mRg" w="max"><radio text="吃饭"/><radio text="睡觉"/><radio text="游戏"/></radio-group></ui>');
ui.show(); //把界面显示出来
var rg = ui.id("mRg"); //根据 id 拿到这个单选按钮组
rg.选中(2);
var i = rg.获取选中下标(); //读出下标
log("选中了第" + (i + 1) + "个");
```


### 获取选中文本()

> “获取选中文本”是 getCheckedText 的中文名字：读出当前选中按钮上的文字。

- 返回 : {String} 选中按钮的文字；一个都没选返回 null


```javascript
var ui = $ui.layout('<ui><statusbar/><radio-group id="mRg" w="max"><radio text="吃饭"/><radio text="睡觉"/><radio text="游戏"/></radio-group></ui>');
ui.show(); //把界面显示出来
var rg = ui.id("mRg"); //根据 id 拿到这个单选按钮组
rg.选中(1);
var t = rg.获取选中文本(); //读出文字
log("你选了:" + t);
```
