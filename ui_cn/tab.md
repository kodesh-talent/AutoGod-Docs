# 标签布局

- 更新时间:2026-10-22 10:58:42

> 标签布局-tab
> 
> 原生类型:{com.google.android.material.tabs.TabLayout}




## 一、常用属性


### 项目 - 选项标签

> 选项标签
> 
> icon/图标：用于指定图标，可以填写图标库的名称，也可以填写图标的相对路径或者绝对路径


```html
// 将布局保存为字符串；标签表示控件，标签中的属性决定显示效果。
var 布局内容 = `
<界面>
    <状态条 />
    <标签布局>
        <项目 文本="选项1" 图标="ag_logo" 图标颜色="#FF0000" />
        <项目 文本="选项2" 图标="ag_logo" 图标颜色="#00FF00" />
    </标签布局>
</界面>
`;
// 解析布局后得到界面对象，显示它即可查看本节属性的效果。
var 界面 = $界面.解析布局(布局内容);
界面.显示();
```


### 内边距 - 内边距

> 设置内边距
> 
> 参数顺序:左,上,右,下(单位:dp)


```html
// 将布局保存为字符串；标签表示控件，标签中的属性决定显示效果。
var 布局内容 = `
<界面>
    <状态条 />
    <标签布局 内边距="20,20,20,20" />
</界面>
`;
// 解析布局后得到界面对象，显示它即可查看本节属性的效果。
var 界面 = $界面.解析布局(布局内容);
界面.显示();
```
