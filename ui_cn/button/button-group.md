# 按钮组

- 更新时间:2026-10-22 10:58:39

> 按钮组-button-group
> 
> 是布局父类的(XLayout)的子类
> 
> 原生类型:{com.google.android.material.button.MaterialButtonToggleGroup}




## 一、常用属性


### 方向 - 布局方向

> 设置布局方向
> 
> 可选参数:v(纵向),h(横向)


```html
// 将布局保存为字符串；标签表示控件，标签中的属性决定显示效果。
var 布局内容 = `
<界面>
    <状态条 />
    <按钮组 方向="横向">
        <按钮 文本="按钮1"/>
        <按钮 文本="按钮2"/>
    </按钮组>
</界面>
`;
// 解析布局后得到界面对象，显示它即可查看本节属性的效果。
var 界面 = $界面.解析布局(布局内容);
界面.显示();
```

### 选中(下标)

> 选中按钮

- 参数 : 下标 {int} 按钮下标


```javascript
//解析布局,获得界面对象
var 界面 = $ui.解析布局("./资源/主界面.xml");
//获得控件
var 按钮组 = 界面.找控件("我的按钮组");
//选中按钮
按钮组.选中(0);
```


### 监听选中(回调函数)

> 监听选中按钮的下标

- 参数 : 回调函数 (function(下标) {}) 回调函数


```javascript
//解析布局,获得界面对象
var 界面 = $ui.解析布局("./资源/主界面.xml");
//获得控件
var 按钮组 = 界面.找控件("我的按钮组");
//监听选中按钮的下标
按钮组.监听选中(function(下标) {
    $ui.土司("当前下标:"+下标);
});
```
