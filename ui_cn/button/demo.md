## 再次修改按钮文字

前面的完整示例已绑定返回和点击事件。下面这段仅用于继续练习英文版本：
在运行英文示例后接着执行，沿用其中的 ui 对象，不需要另建布局文件。


```html
// 找到的按钮就是前面布局中 id 为 button 的那一个。
var button = ui.id("button");
button.setText("再次点击试试"); // 改变显示文字，不会改变原有点击事件。
```
