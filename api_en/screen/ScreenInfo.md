# ScreenInfo - 屏幕信息

- 更新时间:2026-10-22 10:55:42

> 当前手机屏幕的各项尺寸与状态信息（ScreenInfo）。
> 
> 用 $screen.info() 拿到一个，里面装着屏幕宽高、密度、状态栏/导航栏高度等。字段可以直接读，
> 也提供读取方法。中英文数据副本不会因直接赋值而自动同步；信息是查询时的快照，宽高单位为像素。



```javascript
var info = $screen.info();        //拿到屏幕信息
log("屏幕宽=" + info.w);          //直接读字段
log("屏幕高=" + info.getH());     //也可以用方法
```




### const {int} w;

> 保存屏幕宽度。
> 
> 类型为 int。单位像素，读取时会按工具类的横竖屏判断调整宽高，不一定等于应用内容区宽度。
> 这是一份查询时的信息快照；再次读取此对象不会刷新数据，需要重新调用屏幕信息入口。
> 中英文字段是独立保存的两份数据；设置方法会同时赋值，但直接修改一份不会同步另一份，也不会改变真实屏幕。
> 新建而未填充时初值为 -1，表示没有有效测量值；参与计算前应检查。


```javascript
var info = $screen.info(); // 取得当前屏幕信息。
if (info != null) {
    var value = info.w;
    if (value >= 0) {
        log("屏幕宽度：" + value);
    } else {
        log("这项屏幕信息尚未填充。");
    }
}
```

### getXdpi()

> 读取水平密度。
> 
> 类型为 float。来自系统上报的 xdpi，表示水平方向每英寸像素数；这里只保存系统报告值。
