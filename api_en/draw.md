# $draw - 全屏绘制

- 更新时间:2026-10-22 10:55:48

> 全屏绘制（悬浮窗画在屏幕最上层）相关方法，可在屏幕上画方框、准心、点、文字、圆、图片、直线、路径，也能在屏幕上叠加日志文字，常用于游戏脚本里给找图找色结果打标记。
> 绘制相关方法。



```javascript
var canDraw = $draw.getPermit();
```




### 系统限制

在全局绘制框架中，绝大多数情况都会使用到全屏悬浮窗，但是这种方式在部分手机上用户手势会被拦截，这一类现象被称为"卡悬浮"。

不带坐标的日志方法（只传文字的 i/d/w/e/v）会走小型悬浮窗：
//这种悬浮窗是小型的，因此不会阻碍到用户手势(无论在任何系统中都适用)
$draw.i("信息");
$draw.d("调试");
$draw.w("警告");
```

带坐标的绘制（画方框、画直线，以及带 x、y 的日志文字）需要用到全屏悬浮窗：

//这种全屏悬浮窗在部分手机上可能出现"卡悬浮"，需要在系统设置里把悬浮窗权限全开
$draw.i("信息",100,100);
$draw.d("调试",100,100);
$draw.w("警告",100,100);
$draw.rect(100,100,200,200); //绘制方框
$draw.line(100,100,200,200); //绘制线条
```

无论用哪种悬浮窗，绘制前都要先调用 $draw.getPermit() 获取悬浮窗权限。


作为开发者，你必须谨慎使用全局绘制，并不是所有手机都开放了全屏悬浮窗时的触摸事件。

无论用哪种悬浮窗，绘制前都要先调用 $draw.getPermit() 获取悬浮窗权限。

### getPermit()

> 获取悬浮窗权限

- 返回 : {boolean} 已开启悬浮窗权限返回 true，否则返回 false
- 版本 : 1.0.0


```javascript
$draw.getPermit();
```


### rect(rect)

> 在屏幕上画一个空心方框（矩形边框）。

- 参数 : rect {Rect} 要画的矩形区域对象 Rect（含 x、y、宽、高）
- 版本 : 1.0.0


```javascript
//绘制矩形

$draw.rect(rect);
```
