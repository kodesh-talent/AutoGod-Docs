> 全局坐标适配器，用项目中的屏幕配置描述设计分辨率，并换算脚本坐标和图片尺寸。
> 
> 作用是让同一份脚本和图片素材，能在不同分辨率的手机上都跑得准：
> 你在"开发机"上按一套分辨率写好坐标、裁好图，到了用户手机上，$adapt 会按屏幕差异自动把坐标和图片
> 等比例换算过去，不用为每款手机单独调。需要先在项目里配置好开发时的屏幕宽高、dpi 等信息。



```javascript
var x = $adapt.getPx(480); //把开发机上的 480 像素，换算成当前手机上的实际像素
log("换算后坐标：" + x);
```

### getPx(devPx)

> 将开发像素值转换为设备像素值
> 
> 将开发像素值转换为当前设备像素值。请先使用适配器配置开发屏幕密度；此方法会根据该密度换算为 dp，再根据当前设备密度换算为像素。
> 
> 如果开发设备与当前设备的密度相同，直接返回开发像素值。

- 参数 : devPx {int} 开发机上的像素值（你写脚本时依据的那个坐标）
- 返回 : {int} 换算到当前手机上的实际像素值；若未配置开发 dpi 或两台设备 dpi 相同，则原样返回 devPx


```javascript
$adapt.setDensity(2.75);
var px = $adapt.getPx(100);
log("当前设备像素", px);
```
