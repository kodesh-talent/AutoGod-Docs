# $screen - 屏幕操作

- 更新时间:2026-10-22 10:55:51

> 屏幕操作对象（脚本里写作 $screen），用来截屏、查询屏幕宽高/密度、控制屏幕亮度和方向、判断息屏亮屏等。
> 
> 它最常用的功能就是“截一张当前屏幕的图”：做找图找色、AI 识别之前，都得先截屏拿到一张 Image 图片对象。
> 截屏有两种权限来源：安卓 11 以上可以用无障碍服务截屏，否则需要用户授权录屏权限。
> 用之前一般要先 hasPermit() 检查有没有权限，没有就 getPermit() 去申请。



```javascript
// 先检查有没有截屏权限
var allowed = $screen.hasPermit();
if (allowed) {
    var image = $screen.getScreen(); //有了权限就截一张图
    log("截屏成功，宽高=" + image.getWidth() + "x" + image.getHeight());
}
```




### getPermit()

> 申请并等待截屏权限拿到手（会阻塞脚本，直到用户授权成功）。
> 
> 如果已经有权限，立刻返回 true；否则会弹出系统的录屏授权弹窗，然后卡住等待用户点“允许”。
> 用户授权成功后才会继续往下走。注意这个方法是“阻塞等待”的，在用户没点之前脚本停在这里。

- 返回 : {boolean} 成功拿到截屏权限返回 true
- 版本 : 1.0.0


```javascript
//等待获取截屏权限（会弹出授权框，等用户点允许）
$screen.getPermit();
//拿到权限后就可以截屏了
var img = $screen.getScreen();
```


### getPermitOnce()

> 只弹出一次授权框，但不等待用户授权（立刻返回）。
> 
> 和 getPermit() 的区别：getPermit() 会卡住等用户点完才往下走；这个方法只是“弹出授权请求”，
> 然后立刻返回，不等结果。适合你想先把授权框弹出来、稍后再自己 hasPermit() 检查的场景。
> 如果已经有权限，则什么也不做。


```javascript
//获取截屏权限一次（只弹窗，不阻塞等待）
$screen.getPermitOnce();
```


### hasPermit()

> 检查当前有没有截屏权限（不会弹窗，只判断）。
> 
> 返回 true 就说明可以直接 getScreen() 截屏了；返回 false 说明还没授权，需要先 getPermit() 去申请。
> 它会综合判断：如果设置了只用录屏权限就查录屏权限；否则优先看无障碍截屏（安卓11+）是否可用。
> 注意在 MuMu 模拟器上无障碍截屏不可用，会返回 false。

- 返回 : {boolean} 有截屏权限返回 true，否则返回 false
- 版本 : 1.1.5


```javascript
if($screen.hasPermit()){
    log("有截屏权限");
} else {
    $screen.getPermit(); //没有就去申请
}
```


### hasRecord()

> 检查当前有没有录屏权限（只判断录屏这一种，不看无障碍截屏）。
> 
> 和 hasPermit() 的区别：hasPermit() 会综合判断无障碍截屏和录屏两种；这个方法只看“录屏权限”是否已开启。
> 返回 true 表示录屏截屏可用。

- 返回 : {boolean} 有录屏权限返回 true，否则返回 false
- 版本 : 1.7.4


```javascript
if($screen.hasRecord()){
    log("有录屏权限");
}
```


### onlyRecord(onlyRecord)

> 设置是否“只使用录屏权限”来截屏。
> 
> 默认情况下，安卓 11+ 会优先用无障碍服务截屏（更快更方便），只有不可用时才退回录屏权限。
> 如果你传 true，就强制只用录屏权限截屏，不再尝试无障碍截屏。MuMu 模拟器上会自动开启这个模式。

- 参数 : onlyRecord {boolean} 传 true 表示只用录屏权限；传 false 表示恢复默认（优先无障碍）
- 版本 : 1.7.4


```javascript
//设置只使用录屏权限获取截屏
$screen.onlyRecord(true);
```


### getScreen()

> 截一张当前屏幕的图，返回一张 Image 图片对象。
> 
> 这是最常用的截屏方法：它会优先用安卓 11+ 的无障碍截屏，失败再退回录屏权限截屏。
> 截图成功后返回一个 Image 对象，之后可以传给找图找色、AI 识别，或者用 $img.show 显示。
> 如果没有截屏权限、或截屏失败，会在日志里提示并返回 null。

- 返回 : {Image} 当前屏幕的截图对象；无权限或截屏失败时返回 null
- 版本 : 1.0.0


```javascript
//等待获取截屏权限
$screen.getPermit();
var img = $screen.getScreen();//获得屏幕截屏
if (img != null) {
    $img.show(img);//显示截屏
}
```


### bright(bright)

> 设置屏幕亮度（0 到 255 之间）。
> 
> 0 最暗、255 最亮。超出范围会报错忽略。需要“修改系统设置”权限（用 $permit.set() 获取）。

- 参数 : bright {int} 亮度值，范围 0 到 255；0 最暗，255 最亮
- 版本 : 1.0.0


```javascript
//设置屏幕亮度（100 约为中等偏暗）
$screen.bright(100);
```


### dir(degree)

> 设置屏幕方向（强制竖屏/横屏/自动旋转）。
> 
> 需要“修改系统设置”权限。传不同的角度数字会把屏幕锁到对应方向：
> 0 竖屏、90 右转横屏、180 倒置竖屏、270 左转横屏；传 -1 或其他数字表示取消强制、恢复自动旋转。

- 参数 : degree {int} 方向角度：0 竖屏、90 右转横屏、180 倒置竖屏、270 左转横屏；其他数字为自动旋转
- 版本 : 1.0.0


```javascript
//设置屏幕方向
$screen.dir(0);//(强制)竖屏
$screen.dir(90);//(强制)右转横屏
$screen.dir(180);//(强制)倒置竖屏
$screen.dir(270);//(强制)左转横屏
$screen.dir(-1);//(不强制)自动旋转(任何其他数字都是自动旋转)
// 模拟器测试：
// 逍遥     安卓5  : 成功旋转屏幕 会闪退
// 逍遥     安卓7  : 成功旋转屏幕 会闪退
// 逍遥     安卓9  : 成功旋转屏幕 会闪退
// 逍遥     安卓12 : 完美!!!
// 雷电     安卓9  : 毫无反应
//真机测试：
//大多数真机都能正常强制旋转
```


### getHeight()

> 获取屏幕的高度（像素）。
> 
> 返回当前屏幕可显示区域的高度，单位是像素。它会先读取一次屏幕信息再给出高度。
> 注意这是“当前方向”下的高度：竖屏时高度是长的那一边，横屏时高度是短的那一边。

- 返回 : {int} 屏幕高度，单位像素
- 版本 : 1.0.0


```javascript
var w = $screen.getWidth();
var h = $screen.getHeight();
log("屏幕宽高 " + w + "x" + h);
```


### getWidth()

> 获取屏幕的宽度（像素）。
> 
> 返回当前屏幕可显示区域的宽度，单位是像素。它会先读取一次屏幕信息再给出宽度。
> 注意这是“当前方向”下的宽度：竖屏时宽度是短的那一边，横屏时宽度是长的那一边。

- 返回 : {int} 屏幕宽度，单位像素
- 版本 : 1.0.0


```javascript
var w = $screen.getWidth();
var h = $screen.getHeight();
log("屏幕宽高 " + w + "x" + h);
```


### getScreenInfo()

> 查询并返回一份屏幕信息。
> 
> 输入参数：无；返回类型为 ScreenInfo，包含宽高、密度、方向以及系统栏的高度和显示状态。
> 每次调用创建并填充一个新对象；已有对象不会随旋转或界面变化自动刷新。需要新数据时重新调用本方法。
> 宽高单位为像素，取值受工具类的方向判断及强制横竖屏设置影响；它们不等同于应用内容区的可用尺寸。
> 读取信息不等于取得截图，也不会申请截屏权限。调用依赖应用的界面环境，环境未准备好时可能抛出异常。
> 中英文公开字段是两份数据，直接改字段只改变这个对象，不能改变设备分辨率或系统栏状态。

- 返回 : {ScreenInfo} 本次查询的屏幕信息对象，读取其成员不会再次刷新屏幕状态
- 版本 : 1.0.0


```javascript
try {
    var info = $screen.getScreenInfo(); // 获取当前快照。
    if (info != null) {
        log("宽度（像素）：" + info.getW());
        log("高度（像素）：" + info.getH());
        log("密度因子：" + info.getDensity());
        log("工具判断为竖屏：" + info.isVertical());
        // 导航栏高度与是否显示是独立记录，不要无条件扣除高度。
        log("导航栏显示：" + info.isNavShow());
        log("导航栏高度：" + info.getNavH());
    }
} catch (error) {
    log("暂时无法取得屏幕信息：" + error);
}
```

### getDensity()

> 获取屏幕密度因子（density）。
> 
> 密度是“系统把多少像素当成一个逻辑单位”的比例。常见值：ldpi 约 0.75、mdpi 约 1.0、
> hdpi 约 1.5、xhdpi 约 2.0、xxhdpi 约 3.0。做界面适配、按比例换算坐标时会用到它。

- 返回 : {float} 屏幕密度因子（例如 2.0 表示 xhdpi）
- 版本 : 1.0.0


```javascript
var density = $screen.getDensity();
log("当前设备的密度因子：" + density);
```


### isScreenOff()

> 检查屏幕是否熄灭（息屏状态）。
> 
> 返回 true 表示屏幕当前是黑着的、没点亮；返回 false 表示屏幕亮着。做自动化时常用它判断要不要先亮屏。

- 返回 : {boolean} 屏幕已熄灭返回 true，亮着返回 false
- 版本 : 1.0.0


```javascript
if($screen.isScreenOff()){
    log("屏幕息屏");
}
```


### isScreenOn()

> 检查屏幕是否点亮（亮屏状态）。
> 
> 返回 true 表示屏幕当前是亮着的；返回 false 表示屏幕已熄灭。它和 isScreenOff() 正好相反。

- 返回 : {boolean} 屏幕已点亮返回 true，熄灭返回 false
- 版本 : 1.0.0


```javascript
if($screen.isScreenOn()){
    log("屏幕亮屏");
}
```


### split(tranCut, vertCut, index)

> 把整个屏幕按行列切成若干小块，返回其中某一块的矩形范围（Rect）。
> 
> 比如横向切 3 份、纵向切 3 份，整个屏幕就被分成 3x3=9 个格子，编号从 0 开始（从左到右、从上到下）。
> 传 index=8 就拿到右下角那一格。返回的 Rect 里包含这一格的左上角坐标和宽高，可直接给找图找色或画框用。
> 索引超出范围会自动夹到最后一格或第 0 格。这个功能对做“全屏自适应”脚本很有用。

- 参数 : tranCut {int} 横向切几份（列数），传 0 表示不切
- 参数 : vertCut {int} 纵向切几份（行数），传 0 表示不切
- 参数 : index {int} 要取第几格，从 0 开始编号（从左到右、从上到下）
- 返回 : {Rect} 对应那一格的矩形范围（含左上角坐标和宽高）
- 版本 : 1.1.2


```javascript
$draw.closeAll();
//将屏幕分割成9份，找到最后一份的范围
var region = $screen.split(3, 3, 8);
//绘制出这个范围
$draw.rect(region);
```


### save(path)

> 截一张当前屏幕，并直接保存成图片文件到指定路径。
> 
> 它内部就是先 getScreen() 截屏，再把那张图存到 path。需要先有截屏权限，否则会提示“没有截屏权限”。
> 支持相对路径和绝对路径，保存格式由文件后缀决定（如 .png）。

- 参数 : path {String} 保存图片的完整路径（含文件名和后缀，如 /sdcard/Pictures/a.png）
- 版本 : 1.0.0


```javascript
//截屏并且保存(支持相对路径写法)
var imgPath = "/sdcard/Pictures/截屏.png";
$screen.save(imgPath);
```


### mustV()

> 强制按竖屏方向来截（即使当前屏幕是横的，截图也按竖屏处理）。
> 
> 一般情况下用不到：默认会自动检测横竖屏。它是为少数横竖屏识别异常的设备准备的。
> 调用后截屏时会强制按竖屏方向处理。

- 版本 : 1.1.8


```javascript
$screen.mustV();//强制竖屏截屏
```


### mustH()

> 强制按横屏方向来截（即使当前屏幕是竖的，截图也按横屏处理）。
> 
> 一般情况下用不到：默认会自动检测横竖屏。它是为少数横竖屏识别异常的设备、或平板类设备准备的。
> 调用后截屏时会强制按横屏方向处理。

- 版本 : 1.1.8


```javascript
$screen.mustH();//强制横屏截屏
```


### cancelMust()

> 取消之前设置的“强制竖屏/横屏”，恢复成自动检测。
> 
> 默认就是自动检测横竖屏，所以正常情况下根本不需要调用 mustV/mustH/cancelMust 这三个。
> 如果你之前调用过 mustV() 或 mustH()，用这个方法可以取消强制、恢复自动判断。

- 版本 : 1.1.8


```javascript
$screen.cancelMust();//取消强制横竖屏(默认是:自动检测)
```
