# 手势路径

- 更新时间:2026-10-22 10:55:45

> 手势路径（一次“手指划过屏幕”的完整轨迹记录）。
> 
> 它把一次手势录了下来：手指走了哪条线（path）、什么时候开始（startTime）、一共划了多久（duration）。
> 一般由手势录制功能产生，之后再交给手势播放功能去重复刚才的动作，普通用户很少自己创建。



```javascript
//手势路径通常是录制手势后由系统返回的对象，这里演示如何读取它里面的数据
log("开始时间点：" + actPath.startTime);   //这段轨迹从第几毫秒开始
log("一共持续：" + actPath.duration + " 毫秒"); //这段轨迹划了多久
log("轨迹对象：" + actPath.path);           //手指划过的整条路线
```




### const {Path} path;

> 手指划过的整条轨迹（安卓原生 Path 路径对象）。
> 
> 它记录了这次手势从头到尾经过的所有点连成的路线。一般由手势录制产生，普通用户不用自己造。


```javascript
//actPath 是录制得到的手势路径对象
log("轨迹对象：" + actPath.path); //读取这次手指划过的路线
```


### const {int} startTime;

> 这段轨迹开始的时间点（整数，单位：毫秒）。
> 
> 表示这次手势是从整个录制过程的第几毫秒开始动手指的，配合 duration 一起用。


```javascript
log("这段手势从第几毫秒开始：" + actPath.startTime);
```


### const {int} duration;

> 这段轨迹一共持续了多久（整数，单位：毫秒）。
> 
> 1000 毫秒等于 1 秒。表示这次手势从手指按下到抬起一共花了多长时间。


```javascript
log("这段手势持续：" + actPath.duration + " 毫秒");
```
