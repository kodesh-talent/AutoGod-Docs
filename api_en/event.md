# $event - 事件监听

- 更新时间:2026-10-22 10:55:46

> 事件监听对象，脚本里叫 $event。
> 
> 它用来"监听手机上发生的各种事情"：比如网络变化、WiFi 开关、收到某个系统/无障碍事件等。
> 你提前登记一个事件名和回调函数，以后这件事一旦发生，系统就会自动把相关数据送进你的回调。
> 事件分三大类：系统事件、无障碍事件、软件内部事件；其中无障碍类事件需要先开启无障碍权限才能收到。



```javascript
$event.on("wifi", function(data) {
    log(data);
});
```




### on(name, callback)

> 注册一个唯一事件监听器。
> 
> 这里的"唯一"意思是：同一个事件名全局只保留一个监听器，后注册的会覆盖之前的。
> 
> 适合那些"我只关心这件事发生时做一件事"的场景。
> 
> 事件分三大类：系统事件、无障碍事件、软件内部事件。系统事件一般不需要额外权限，
> 但个别如蓝牙需要附近设备和位置权限；无障碍类事件则必须先在系统里开启无障碍服务才能收到。
> 
> 监听的事件名要和系统会发出的事件名一致（例如 "wifi"），否则永远触发不到。

- 参数 : name {string} 要监听的事件名，例如 "wifi"
- 参数 : callback {function} 事件发生时要执行的回调，参数 data 是事件附带的数据


```javascript
//监听 WiFi 状态变化这个事件
$event.on("wifi", function(data) {
    //事件发生时会回调到这里，data 里是事件附带的数据
    log(data);
});
```


### add(name, callback)

> 添加事件监听器（加入"监听器列表"）。
> 
> 和 on 不同：这里每调用一次就追加一个监听器，即使事件名相同也会并存，事件触发时会全部依次执行。
> 
> $event 有两种监听器：唯一监听器（on）和监听器列表（add）。
> 
> 唯一监听器全局只留一个，重复设置会互相覆盖。
> 
> 监听器列表可以重复添加多个，允许同名。
> 
> 软件重启后监听器列表会被清空，需要重新注册。

- 参数 : name {string} 要监听的事件名
- 参数 : callback {function} 事件发生时要执行的回调，参数是事件附带的数据


```javascript
$event.add("sample", function() { log("done"); });
```


### ls()

> 列出监听器列表里所有已添加的事件名。
> 
> 只统计通过 add（添加）加入列表的那些，不包括 on（唯一监听器）。

- 返回 : {string[]} 已添加进列表的事件名列表；一个都没有时返回空列表


```javascript
var result = $event.ls();
log(result);
```


### clear()

> 清空监听器列表里所有已添加的事件监听器。
> 
> 只清空 add（添加）加入列表的那些，不影响 on 设置的唯一监听器。


```javascript
$event.clear();
```
