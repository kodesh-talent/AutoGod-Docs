# MenuBody - 按钮容器

- 更新时间:2026-10-22 10:55:53

> 悬浮球菜单的按钮容器（MenuBody）。
> 
> 它是一个“圆盘”：屏幕上有一个可以拖动的主按钮，点一下，周围会展开一圈小按钮，再点一下又收回去。
> 用 $arc.body(名字) 创建一个容器，然后用 添加() 往里放按钮——第一个放进去的就是主按钮，
> 之后放的都是展开后才出现的小按钮，最后调 显示() 把它显示到屏幕上。



```javascript
var 菜单 = $arc.body("tools");                 //创建一个名为 tools 的容器
菜单.添加($arc.item("ic_menu"));               //第一个按钮成为主按钮
菜单.添加($arc.item("ic_settings"));           //后续按钮是展开后的小按钮
菜单.显示();                                   //显示悬浮球
```




### add(menu)

> 往这个菜单容器里加一个按钮。
> 
> 第一个加进去的按钮会成为主按钮（平时屏幕上那个），之后加的按钮会在主按钮展开时围成一圈出现。
> 返回容器自己，可以接着链式继续添加。

- 参数 : menu 要加进去的按钮，用 $arc.item(图标) 创建
- 返回 : 当前容器自己，可继续链式添加或设置
- 版本 : 1.0.0


```javascript
var 菜单 = $arc.body("tools");
菜单.add($arc.item("ic_menu"));      //主按钮
菜单.add($arc.item("ic_settings"));  //展开后出现的小按钮
菜单.show();
```


### show()

> 把这个悬浮球菜单真正显示到屏幕上。
> 
> 要先添加至少一个按钮再调它。如果同名菜单已经显示过了，这次不会重复创建。
> 第一次显示时 Android 可能会弹出“显示在其他应用上层”的悬浮窗权限请求。

- 版本 : 1.0.0


```javascript
var 菜单 = $arc.body("tools");
菜单.add($arc.item("ic_menu"));
菜单.add($arc.item("ic_settings"));
菜单.show();
```


### name(name)

> 给这个菜单起一个唯一的名字。
> 
> 要在 show() 之前设置。同时显示的菜单名字不能重复：如果这个名字已经被别的菜单用了，
> 本菜单就不会显示。返回容器自己，可链式继续。

- 参数 : name 菜单的唯一名字
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.0.0


```javascript
var 菜单 = $arc.body("tools").name("tools-menu");
菜单.add($arc.item("ic_menu")).show();
```


### margin(left, right)

> 设置主按钮贴到屏幕左、右边缘时，离屏幕边保留的距离。
> 
> 单位是像素。贴到左边用第一个值，贴到右边用第二个值，默认都是 0（紧贴屏幕边）。
> 返回容器自己，可链式继续。

- 参数 : left 贴到屏幕左边时保留的像素距离，默认 0
- 参数 : right 贴到屏幕右边时保留的像素距离，默认 0
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.0.0


```javascript
var 菜单 = $arc.body("tools").margin(16, 24);
```


### radius(radius)

> 设置小按钮从主按钮向外展开的距离（展开半径）。
> 
> 单位是 dp，默认 80。数值越大，小按钮离主按钮越远。返回容器自己，可链式继续。

- 参数 : radius 展开半径，单位 dp
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.0.0


```javascript
var 菜单 = $arc.body("tools").radius(96);
```


### global(isGlobalShow)

> 设置回到手机桌面后，这个悬浮球还继不继续显示。
> 
> 默认 true：退到桌面也一直显示。传 false，应用一退到后台就把悬浮球藏起来。
> 跨应用显示需要 Android 悬浮窗权限。返回容器自己，可链式继续。

- 参数 : isGlobalShow 退到后台后是否继续显示，默认 true
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.0.0


```javascript
var 菜单 = $arc.body("tools").global(false);
```


### dur(expandAnimDur)

> 设置小按钮展开、收起时动画的播放时长。
> 
> 单位是毫秒，默认 250。数值越大动画越慢。返回容器自己，可链式继续。

- 参数 : expandAnimDur 动画时长，单位毫秒
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.0.0


```javascript
var 菜单 = $arc.body("tools").dur(500);
```


### x(x)

> 设置主按钮第一次显示时的横向位置（离屏幕左边多远）。
> 
> 单位像素，只在悬浮窗第一次显示时生效。返回容器自己，可链式继续。

- 参数 : x 初始横坐标，单位像素
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.0.0


```javascript
var 菜单 = $arc.body("tools").x(120);
```


### y(y)

> 设置主按钮第一次显示时的纵向位置（离屏幕顶部多远）。
> 
> 单位像素，只在悬浮窗第一次显示时生效。返回容器自己，可链式继续。

- 参数 : y 初始纵坐标，单位像素
- 返回 : 当前容器自己，可继续链式调用
- 版本 : 1.0.0


```javascript
var 菜单 = $arc.body("tools").y(300);
```
