> 结果排序规则表




结果排序规则表

用一个数字来指定：识别出多个目标之后，按什么顺序把它们排列好。
做文字识别时，排序方向决定了"从上到下、从左到右"读出文字的顺序；选错了，读出的字就会乱序。
下面这张表列出了所有可选数字及其含义：

|--------|------------|------------------------------|
| -1     | 不排序（默认）    | 不对识别结果集进行任何排序操作（追求效率可选）      |
| 1      | 从左到右       | 按矩形框的x坐标升序排列（x越小，越靠左，排在前面）   |
| 2      | 从右到左       | 按矩形框的x坐标降序排列（x越大，越靠右，排在前面）   |
| 3      | 从上到下       | 按矩形框的y坐标升序排列（y越小，越靠上，排在前面）   |
| 4      | 从下到上       | 按矩形框的y坐标降序排列（y越大，越靠下，排在前面）   |
| 5      | 从左上到右下     | 按矩形框x+y的和升序排列（左上区域值更小，排在前面）  |
| 6      | 从右上到左下     | 按矩形框x-y的差降序排列（右上区域差值更大，排在前面） |
| 7      | 从左下到右上     | 按矩形框x-y的差升序排列（左下区域差值更小，排在前面） |
| 8      | 从右下到左上     | 按矩形框x+y的和降序排列（右下区域值更大，排在前面）  |
| 9      | 从左到右并且从上到下 | 优先按x坐标升序，x相同时按y坐标升序          |
| 10     | 从右到左并且从上到下 | 优先按x坐标降序，x相同时按y坐标升序          |
| 11     | 从左到右并且从下到上 | 优先按x坐标升序，x相同时按y坐标降序          |
| 12     | 从右到左并且从下到上 | 优先按x坐标降序，x相同时按y坐标降序          |
| 13     | 大的面积在前面    | 按矩形框面积降序排列（面积越大，排在前面）        |
| 14     | 小的面积在前面    | 按矩形框面积升序排列（面积越小，排在前面）        |
| 其他（默认） | 从左到右（默认规则） | 按矩形框的x坐标升序排列（与编码1的规则一致）      |


## 具体应用

例如现在我有一个数据集，我主要用来识别数字和一个逗号字符串，我的数据集大多数都是205x30的图片，你觉得我应该用什么样的尺寸比较合适？用什么样的排序规则比较合适？

答案：图片是"宽 205、高 30"的细长横条，所以喂给模型的输入尺寸应该按这个比例来定，
例如高度取 32、宽度取 192（和示例里的 imgsz=[32, 192] 一致），让模型按细长条的样子去学，识别会更准。

排序规则：因为是从左往右读的一排数字和逗号，应该选"从左到右"，也就是规则编号 1（按 x 坐标从小到大排），
这样识别结果才会按照你肉眼阅读的先后顺序输出。


训练 YOLO 模型通常在电脑端使用 Python 完成，本类只负责说明训练完成后如何在 Rhino
脚本中加载模型。训练时可把输入尺寸设置为高度 32、宽度 192，并根据电脑内存调整批次
大小和线程数；这些 Python 参数不是 Rhino 脚本，不能直接粘贴到脚本中执行。
训练完成后请把导出的模型文件和标签文件复制到手机上的实际路径。


```javascript
// 训练步骤在电脑端完成；下面是在手机脚本中加载训练结果的示例。
var 检测器 = $目标检测.创建(12); // 12 表示使用 YOLO12 检测器。
检测器.设置排序方向(1); // 结果按横坐标从左到右排列。
检测器.初始化("/sdcard/yolo/yolo.bin",
    "/sdcard/yolo/yolo.param", "/sdcard/yolo/label.txt");
```


训练结束后应在电脑端用训练工具验证模型效果。验证完成并把模型放到手机后，可以在
Rhino 中调用检测方法；输入是图片对象，输出通常是检测结果集合，具体返回类型以当前
模型实现为准。


```javascript
// 先完成初始化，再读取一张待检测图片。
var 图片 = $图像.读取("/sdcard/yolo/test.png");
var 结果 = 检测器.检测(图片);
if (结果 != null) {
    日志("检测结果数量：" + 结果.size());
}
```


训练好模型后，需要把训练产出的权重文件（通常是 best.pt）放到手机项目里，脚本才能加载使用。

请使用文件管理器或宿主提供的文件复制能力完成传输；下面的脚本只演示复制完成后如何
检查目标路径，不能代替电脑终端命令。


```javascript
// 检查并记录模型文件和标签文件应放置的位置。
var 模型路径 = "/sdcard/yolo/yolo.bin";
var 标签路径 = "/sdcard/yolo/label.txt";
日志("模型路径：" + 模型路径);
日志("标签路径：" + 标签路径);
```


接下来确定排序方向，由于我制作的是文字识别，排序方向当然就是从左到右的，因此代码这么写：


```javascript
var yolo = $yolo.create(12);        //创建一个 YOLO12 检测器对象
yolo.setDir(1);                     //设置结果排序方向为"从左到右"（规则编号 1）
//先初始化模型（参数依次是：模型文件、参数文件、标签文件路径）
yolo.init("/sdcard/yolo/yolo.bin", "/sdcard/yolo/yolo.param", "/sdcard/yolo/label.txt");
```
