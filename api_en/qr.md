# $qr - 二维码工具

- 更新时间:2026-10-22 10:55:50

> 二维码工具，脚本内置入口为 $qr，中文入口为 $二维码。
> 
> 可以把非空文字制作成 Image 图像，也可以从文件、图像或屏幕区域解析二维码中的文字。
> 制作结果不是文件路径；使用完图像后需要回收。识别成功返回 String 字符串。
> 路径解析重载捕获异常后返回 null；图像和屏幕区域解析重载还可能抛出识别异常，所以示例同时检查空值并处理异常。
> 带脚本注解的入口要求安卓七及以上。读取文件需要相应访问权限，识别屏幕需要先取得截屏权限。



```javascript
var image = null; // 保留图像引用，处理结束时释放。
try {
    image = $qr.make("二维码教学示例"); // 把文字画成二维码。
    if (image != null) {
        var content = $qr.parse(image); // 把刚制作的图像解析回文字。
        log(content); // 正常情况下得到原来的文字。
    } else {
        log("没有生成图像，请检查设备版本和输入内容。");
    }
} catch (error) {
    log("二维码处理失败：" + error); // 识别失败也可能抛出异常。
} finally {
    if (image != null) {
        image.recycle(); // 回收后不要再使用这个图像。
    }
}
```




### make(content)

> 把非空文字制作成二维码图像，使用默认外观。
> 
> 输入内容类型为 String，即字符串，可以填写普通文字或网址；生成二维码不会自动打开网址。
> 返回类型为 Image，是可继续调用图像方法的对象，不是路径字符串。使用前检查是否为 null，不再使用时调用回收方法释放内存。
> 这个脚本入口要求安卓七及以上；版本过低或未能生成位图时返回 null。
> 默认宽高各五百像素、边距二，图案黑色、背景白色。
> 不要传入空内容。此重载没有包住所有生成异常，非法输入等情况可能抛出异常，不能把所有失败都当成 null。

- 参数 : content {String} 需要写入二维码的非空文本
- 返回 : {Image} 生成的图像对象；不支持的系统版本或制作失败时可能为 null
- 版本 : 1.2.3


```javascript
var image = null; // 先准备变量，方便最终回收。
try {
    image = $qr.make("教学示例");
    if (image != null) {
        // 返回的是图像对象，可以继续读取尺寸。
        log("宽度：" + image.getWidth());
        log("高度：" + image.getHeight());
    } else {
        log("二维码未能生成，请检查配置和设备版本。");
    }
} catch (error) {
    log("制作二维码时发生异常：" + error);
} finally {
    if (image != null) {
        image.recycle(); // 示例处理结束，释放图像内存。
    }
}
```


### make(content, options)

> 把非空文字制作成二维码图像，并指定外观配置。
> 
> 输入内容类型为 String，即字符串，可以填写普通文字或网址；生成二维码不会自动打开网址。
> 返回类型为 Image，是可继续调用图像方法的对象，不是路径字符串。使用前检查是否为 null，不再使用时调用回收方法释放内存。
> 这个脚本入口要求安卓七及以上；版本过低或未能生成位图时返回 null。
> 第二个参数类型为 Object，会解析成 QrOptions。可用普通脚本对象填写宽、高、边距和颜色，也可以传入 QrOptions 配置对象。
> 默认宽高各五百像素、边距二、黑色图案、白色背景。中文字段不为 null 时优先于对应英文字段。
> 宽高使用正整数，边距使用非负整数；颜色例如 #000000 和 #FFFFFF。边距是编码器留白参数，不是固定像素边距。
> 配置为空或配置版本的生成过程出错时返回 null；配置解析发生在生成的异常处理外层，仍可能抛出异常。

- 参数 : content {String} 需要写入二维码的非空文本
- 参数 : options {Object} 可转换成 QrOptions 的配置，省略字段使用默认值
- 返回 : {Image} 生成的图像对象；不支持的系统版本或制作失败时可能为 null
- 版本 : 1.2.3


```javascript
var image = null; // 先准备变量，方便最终回收。
try {
    // 普通对象中的字段会转换为二维码配置。
    var options = {
        w: 600, h: 600, // 图片尺寸，单位像素。
        margin: 4, // 给图案周围保留空白。
        foreColor: "#000000", bgColor: "#FFFFFF" // 黑白便于识别。
    };
    image = $qr.make("教学示例", options);
    if (image != null) {
        // 返回的是图像对象，可以继续读取尺寸。
        log("宽度：" + image.getWidth());
        log("高度：" + image.getHeight());
    } else {
        log("二维码未能生成，请检查配置和设备版本。");
    }
} catch (error) {
    log("制作二维码时发生异常：" + error);
} finally {
    if (image != null) {
        image.recycle(); // 示例处理结束，释放图像内存。
    }
}
```


### parse(path)

> 读取图片文件并解析其中的二维码文字。
> 
> 返回类型为 String，即二维码保存的文字；不会自动打开其中的网址或执行其中的内容。
> 需要安卓七及以上；系统版本过低时打印提示并返回 null。
> 输入类型为 String，是图片文件路径。请把示例路径改成真实存在且当前脚本有权读取的图片。
> 此重载内部读取图片并捕获读取、解码异常；文件不存在、无法访问或未识别到二维码时返回 null。

- 参数 : path {String} 包含二维码的图片路径，需要有读取权限
- 返回 : {String} 识别出的文字；部分失败情形返回 null，其他情形见上面的异常说明
- 版本 : 1.2.3


```javascript
try {
    // 改成设备上实际存在的二维码图片路径。
    var content = $qr.parse("/sdcard/qr.png"); // 调用本重载。
    if (content != null) {
        log("二维码内容：" + content);
    } else {
        log("未取得识别结果，请检查输入和权限。");
    }
} catch (error) {
    log("解析二维码失败：" + error);
}
```


### parse(image)

> 解析现有图像对象中的二维码文字。
> 
> 返回类型为 String，即二维码保存的文字；不会自动打开其中的网址或执行其中的内容。
> 需要安卓七及以上；系统版本过低时打印提示并返回 null。
> 输入类型为 Image，是已经取得的图像对象。下面先制作一张二维码，示范输入对象的来源和后续释放。
> 输入为空、没有位图或位图已回收时返回 null；有效图片中未找到二维码等解码错误会抛出异常。
> 此方法不会替调用者回收输入图像。由创建或持有图像的脚本在不再使用时回收，不能边识别边回收。

- 参数 : image {Image} 未回收的图像对象；识别完成后仍由调用方负责释放
- 返回 : {String} 识别出的文字；部分失败情形返回 null，其他情形见上面的异常说明
- 版本 : 1.2.3


```javascript
var image = null; // 在最终清理时仍能访问这个变量。
try {
    image = $qr.make("二维码教学示例"); // 创建输入的图像对象。
    if (image == null) {
        log("没有生成测试图像。");
    } else {
        var content = $qr.parse(image); // 调用本重载。
        if (content != null) {
            log("二维码内容：" + content);
        } else {
            log("未取得识别结果，请检查输入和权限。");
        }
    }
} catch (error) {
    log("解析二维码失败：" + error);
} finally {
    if (image != null) {
        image.recycle(); // 示例结束，不再使用这张图片。
    }
}
```


### parse(x, y, w, h)

> 用左上角坐标和宽高指定屏幕识别区域。
> 
> 返回类型为 String，即二维码保存的文字；不会自动打开其中的网址或执行其中的内容。
> 需要安卓七及以上；系统版本过低时打印提示并返回 null。
> 需要事先取得截屏权限并让二维码出现在屏幕上；无法取得截图时返回 null。
> 区域坐标以截图左上角为原点，单位为像素；宽高应为正整数，坐标非负且整个区域必须在截图内。
> 下面的三百乘三百区域只是示范，请按设备截图尺寸和二维码所在位置修改，并包含完整二维码及周围留白。
> 底层裁剪在右侧或下侧越界时可能返回原图而不是期望的小区域，不能用越界坐标作为识别全屏的写法。
> 裁剪或解码错误可能向外抛出异常；未找到二维码不保证返回 null。当前内部图像回收写在正常返回路径，异常时没有保证完成释放，不建议对失败区域进行密集重试。
> 四个输入类型都是 Integer，即整数对象，脚本传整数即可；不要传 null。宽高表示长度，不是右下角坐标。

- 参数 : x {Integer} 左上角横坐标，单位像素
- 参数 : y {Integer} 左上角纵坐标，单位像素
- 参数 : w {Integer} 区域宽度，单位像素，须为正整数
- 参数 : h {Integer} 区域高度，单位像素，须为正整数
- 返回 : {String} 识别出的文字；部分失败情形返回 null，其他情形见上面的异常说明
- 版本 : 1.2.3


```javascript
try {
    // 已取得截屏权限，并确认这个区域包含完整二维码后再运行。
    var content = $qr.parse(0, 0, 300, 300); // 调用本重载。
    if (content != null) {
        log("二维码内容：" + content);
    } else {
        log("未取得识别结果，请检查输入和权限。");
    }
} catch (error) {
    log("解析二维码失败：" + error);
}
```


### parse(region)

> 
> 返回类型为 String，即二维码保存的文字；不会自动打开其中的网址或执行其中的内容。

> 需要事先取得截屏权限并让二维码出现在屏幕上；无法取得截图时返回 null。
> 区域坐标以截图左上角为原点，单位为像素；宽高应为正整数，坐标非负且整个区域必须在截图内。
> 下面的三百乘三百区域只是示范，请按设备截图尺寸和二维码所在位置修改，并包含完整二维码及周围留白。
> 底层裁剪在右侧或下侧越界时可能返回原图而不是期望的小区域，不能用越界坐标作为识别全屏的写法。
> 裁剪或解码错误可能向外抛出异常；未找到二维码不保证返回 null。当前内部图像回收写在正常返回路径，异常时没有保证完成释放，不建议对失败区域进行密集重试。
> 输入类型为 Integer[]，脚本数组会转换成 Java 整数对象数组。前四项依次为横坐标、纵坐标、宽、高，额外元素不会参与裁剪。
> 在成功取得截图后，数组为空或不足四项时打印提示并返回 null。请不要填写空元素。

- 参数 : region {Integer[]} 至少四项的整数数组，前四项按横坐标、纵坐标、宽、高排列
- 返回 : {String} 识别出的文字；部分失败情形返回 null，其他情形见上面的异常说明

try {

### parse(rect)

> 用矩形对象指定屏幕识别区域，解析其中的二维码文字。
> 
> 返回类型为 String，即二维码保存的文字；不会自动打开其中的网址或执行其中的内容。
> 需要安卓七及以上；系统版本过低时打印提示并返回 null。
> 需要事先取得截屏权限并让二维码出现在屏幕上；无法取得截图时返回 null。
> 区域坐标以截图左上角为原点，单位为像素；宽高应为正整数，坐标非负且整个区域必须在截图内。
> 下面的三百乘三百区域只是示范，请按设备截图尺寸和二维码所在位置修改，并包含完整二维码及周围留白。
> 底层裁剪在右侧或下侧越界时可能返回原图而不是期望的小区域，不能用越界坐标作为识别全屏的写法。
> 裁剪或解码错误可能向外抛出异常；未找到二维码不保证返回 null。当前内部图像回收写在正常返回路径，异常时没有保证完成释放，不建议对失败区域进行密集重试。
> 输入类型为 Rect。实际读取 x、y、w、h 四个字段；构造时按横坐标、纵坐标、宽、高的顺序传值。不要传入 null。
> Rect 是脚本内置类名，中英文示例都保留这个名称；修改其他宽高副本不代表本方法读取的 w、h 随之改变。

- 参数 : rect {Rect} 非空矩形对象，实际读取 x、y、w、h 字段
- 返回 : {String} 识别出的文字；部分失败情形返回 null，其他情形见上面的异常说明
- 版本 : 1.2.3


```javascript
try {
    // 已取得截屏权限，并确认这个区域包含完整二维码后再运行。
    var region = new Rect(0, 0, 300, 300); // 创建矩形输入对象。
    log("左上角：" + region.x + "," + region.y);
    log("区域宽高：" + region.w + " × " + region.h);
    var content = $qr.parse(region); // 调用本重载。
    if (content != null) {
        log("二维码内容：" + content);
    } else {
        log("未取得识别结果，请检查输入和权限。");
    }
} catch (error) {
    log("解析二维码失败：" + error);
}
```
