# Rect - 范围对象

- 更新时间:2026-10-22 10:56:19

> 矩形范围对象 Rect，保存左上角位置和宽高。
> 
> 脚本可以直接使用带参数构造方法，没有无参数构造。四个数字依次是横坐标、纵坐标、宽、高。
> 宽高不是右下角坐标。对象本身不检查区域是否合法，也不执行裁剪或识别。
> w、width、宽是独立字段，h、height、高也是独立字段；构造时赋相同值，之后的设置方法并不全部同步。



```javascript
var rect = new Rect(10, 20, 100, 50); // 构造一份一致的范围。
log(rect.getW()); // 读取 w，结果为一百。
rect.setW(80); // 只改变 w。
log(rect.getW()); // 八十。
log(rect.getWidth()); // width 仍是一百。
// 要保持所有副本一致，可按新尺寸重新构造范围。
rect = new Rect(rect.x, rect.y, 80, 50);
log(rect.getWidth()); // 新对象各宽度字段都为八十。
```




### const {int} x;

> 保存横坐标。
> 
> 数据类型为 int（整数），表示所属坐标系中的像素位置或长度；不会自动检查图片边界。
> 宽度三字段 w、width、宽及高度三字段 h、height、高在构造时一致，之后各自独立，修改一份不会自动同步其他份。
> 这是公开字段，可以直接读写。使用接口前应确认该接口究竟读取哪一份宽高字段；不要把某份副本当成自动计算的属性。


```javascript
var rect = new Rect(10, 20, 100, 50); // 创建教学范围。
log(rect.x); // 直接读取公开字段。
```
